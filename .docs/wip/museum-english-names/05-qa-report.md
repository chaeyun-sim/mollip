# 전시장 영문명 데이터 입력 검증

- 대상: `public.museums.name_en`, 기존 빈 값만 입력.
- 조사 기준: `homepage_url`의 공식 제목·로고·영문 페이지 우선, 보완 출처는 기관·지자체·관광기관 자료.
- 전체 489곳 중 279곳 입력 및 저장 후 재조회 일치. 210곳은 미확인 상태로 보류.
- `name`, `homepage_url`, `address` 변경 시 입력을 건너뛰도록 조건부 PATCH 사용.
- 기존 영문명 보존; 전시장 추가/삭제 없음.
- 응답 유실 시 PATCH를 재실행하지 않고 저장된 값을 재조회하여 확인.

## 예외 검증

- 미확인 영문명을 추측하여 입력하지 않음. pending.csv 210건 유지.
- 동명 전시장 주소 불일치 및 잘못 연결된 홈페이지를 보류: id 61, 1449, 1468, 1480.
- concurrent 변경 방어: id + name + address + homepage_url + 기존 name_en 조건 사용.
- 조건 충돌·응답 장애는 이번 적용에서 발생하지 않음. 장애 분기는 실제 장애 주입 미검증.
- 이번 결과는 전체 489건의 영문명 입력 완료를 뜻하지 않음. 남은 210건은 공식 영문명 추가 조사 또는 장소 식별 수정이 필요함.
