# Handoff

전시 시작일·종료일 대신 선택형 방문일 하나를 사용한다. 선택한 날짜는 다음 기록 화면으로 전달되며 다시 변경할 수 있다. 사용자 포스터 레이아웃 유지.

| 기능 / AC   | tsc    | 스크린샷                                      | 인터랙션                          | 회귀                        |
| ----------- | ------ | --------------------------------------------- | --------------------------------- | --------------------------- |
| AC-1 방문일 | 오류 0 | `evidence/visit-date-yesterday.png` 직접 확인 | 선택/해제/과거일 재선택/제출 통과 | 검색→폼→기록 화면 날짜 동일 |

앱 테스트 307개 통과. 전체 실행의 기존 스킬 테스트 11 suites 오류와 최종 레이아웃의 작은 기기/큰 글자/사진 권한/VoiceOver 미검증은 `05-qa-report.md`에 기록했다. 네이티브 모듈 변경·커밋 없음.

설계 검토는 사용자 후속 변경 반영 후 self-review Pass. 독립 에이전트 검수로 표시하지 않음.
