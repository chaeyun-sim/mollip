# Design brief (v3 — 순차 질문 플로우)

## 이력

- v1: 카드 3장 → 사용자 "ugly" (스크린샷 `evidence/v1/`).
- v2: 카드 없는 라벨↔값 목록 → 사용자 "아직도 목록 같다". 참고: v2 파일은 사용자가 직접 문구를 줄였다(재방문 라벨 "재방문 여부", 별점 점수 문구 제거). 최소 문구 취향으로 읽고 v3 카피도 짧게 간다.
- **v3**: 목록을 버리고 **한 번에 한 질문**을 보여주는 순차 플로우. 순서 — 방문일 → 별점 → 오늘 찍은 사진 → 재방문 여부. (시설 평가는 사용자 확인 대기, 이번에 넣지 않음.)

## Design intent

- 한 화면에는 질문 하나. 큰 질문 문장 + 답하는 컨트롤 하나. 나머지는 비운다.
- 지금 어디쯤인지(2/3 안의 n/4)와 뒤로·다음이 늘 같은 자리에 있다.
- v2 색 체계 유지: 근백색 canvas / 코코아 gray600·700·900 / 올리브 moss(선택 상태) / 마호가니 editorial(날짜·점수). plum은 `다음` CTA 하나(기존 inverse 버튼).

## 화면 구성 (공통 골격, iPhone 17 Pro 기준)

```
RecordStepHeader  뒤로 · 기록하기 · 2/3          (기존, 단계 2/3 유지)
──────────────
[진행 바 ━━━────]                    질문 1 / 4     (내부 진행)
[compact 액자 미리보기]   (기존 prop, 36%)
질문 문장 (Hahmlet bold 24/34)
보조 한 줄 (14 gray600, 필요할 때만)

            ← 질문별 컨트롤 (남는 공간) →

[ 뒤로 (ghost) ]  [        다음 (inverse, flex)       ]
```

- 진행: 기존 `ProgressBar`(size normal) + 우측 "1 / 4" 텍스트. 접근성 라벨 "질문 4개 중 1번째". 진행 바 전환은 `animate={!reduceMotion}`.
- 컨텐츠 전환: 질문 컨트롤 영역만 `FadeIn 180ms`. **`useReducedMotion()`이 켜져 있으면 애니메이션 없음** — 이 앱의 기존 패턴(`RecordFramePreview`)과 같은 방식. 슬라이드/바운스 없음.
- 하단 바: 뒤로 + 다음이 항상 같은 위치. 하단 바 배경 `bg-bg-light`.

## 질문별 상세

| #   | 질문(KO)                  | 컨트롤                                                                                                                                                         | 다음 활성 조건                                                  | 비고                                                                                             |
| --- | ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| 1   | 언제 다녀오셨어요?        | 큰 날짜 `10.14 수`(Hahmlet 36, 마호가니) + 캘린더/자물쇠 아이콘 + 밑줄 hairline. 탭 → `DatePickerModal`. 고정일이면 자물쇠 + "도슨트 관람일로 고정"(탭 비활성) | 항상                                                            | 기본값·min/max·고정일 로직 그대로. 고정일일 때도 건너뛰지 않고 **확인 단계**로 유지(Alex 요구 2) |
| 2   | 전시는 어떠셨나요?        | 별 5개 size 44(탭 영역 56), 가운데 정렬. 아래 점수 `4.5 / 5`(마호가니 20). 0점이면 "별을 눌러 남겨요"                                                          | 별점 ≥ 0.5 (필수)                                               | 반 점 안내: "별의 왼쪽을 누르면 반 점이에요"(12 gray600)                                         |
| 3   | 오늘 찍은 사진이 있나요?  | 기존 `PhotoGrid`(3열, 최대 6). 보조 "선택이에요. 최대 6장"                                                                                                     | 항상. 사진 0장이면 주 버튼 라벨 `건너뛰기`, 1장 이상이면 `다음` |                                                                                                  |
| 4   | 이 전시, 다시 찾으셨나요? | 선택지 2개 세로 배치(각 64pt): "네, 다시 찾았어요" / "아니요, 처음이에요"                                                                                      | 둘 중 하나 선택(명시)                                           | 초기 미선택. `isRevisit` true/false 저장. 마지막이라 `다음` → 캡션                               |

### 선택지(재방문) 스타일

- 미선택: `bg-surface-neutral`(채움, 외곽선 없음) + 왼쪽 빈 원 링(gray600 1.5px).
- 선택: `bg-white` + `border-[1.5px] border-moss` + 올리브로 채운 원 안 흰 체크. 색 외에 **체크 아이콘·굵은 글씨(semibold)**로도 구분.
- `accessibilityRole="radio"`, `accessibilityState={{ checked }}`, 두 선택지는 `accessibilityRole="radiogroup"` 컨테이너.

## 이동·상태 규칙

- 상태의 원천은 `draft.writeStep`(`'date'|'rating'|'photos'|'revisit'`). 없으면 첫 단계.
- `다음`: 다음 단계로 `writeStep` 갱신. 마지막 단계는 `dateKey` 확정 후 `/diary/record/caption`으로 이동하며 `writeStep='revisit'`을 남겨 캡션에서 뒤로 오면 복원.
- `뒤로`(하단/헤더 둘 다 같은 동작): 이전 단계로. 첫 단계에서는 `router.back()`(1단계로).
- iOS 스와이프 백은 첫 단계가 아닐 때 비활성(`gestureEnabled`), Android 하드웨어 뒤로는 이전 질문으로. — 전체 화면에서 갑자기 빠지지 않게.
- 답은 모두 draft에 있으므로 이동·복귀에서 유지된다.

## 레이아웃 예산 (874pt)

헤더 ~110 + 진행 ~28 + 액자 compact ~200 + 질문 문장 ~70 + 컨트롤 최대 ~230(사진 그리드 2행 포함 시 스크롤) + 하단 바 ~96. 사진 6장일 때만 내용이 넘쳐 스크롤(ScrollView 유지).

## Accessibility

- 터치 타겟 ≥ 44pt: 별 44 + hitSlop, 선택지 64, 하단 버튼 ≥ 44(기존 Button large), 날짜 행 ≥ 56.
- 진행 바 `progressbar` + 값, 텍스트 "1 / 4"는 접근성 라벨로 대체.
- 질문 문장은 `accessibilityRole="header"`. 단계가 바뀌면 질문이 새로 렌더되어 스크린리더가 읽는다.
- 대비(계산값): gray600/canvas 5.49, 별 gray700 8.03, 마호가니 6.92, 흰/올리브 4.67, 올리브 테두리/흰 4.47(≥3).
- Reduce Motion: 페이드·진행 바 애니메이션 모두 비활성.
