# Spec — 홈 하단 발견 섹션 리디자인 (인기 · 국립 기관 · 추천)

## Problem

- 직전 리프레시로 상단(헤더·검색·히어로·FAB)은 승인됐으나, 하단 3개 섹션은 구형 레이아웃 그대로다.
- "요즘 인기 있는 전시"는 제목·장소 없이 56px 원형 아바타만 있어 무엇인지 알 수 없다.
- "국립 기관 전시"와 "추천"이 같은 140px 가로 카드 줄이라 위계·차별이 없고, 국립 카드에는 근거 없는 `01/02` 번호가 붙는다.

## Goals

- 인기: 포스터+텍스트(제목·장소·상태)가 읽히는 컴팩트 에디토리얼 행을 하나의 컨테이너 컬렉션으로.
- 국립 기관: 따뜻한 톤온톤 갤러리 밴드 + 큰 세로 포스터 가로 갤러리 + 읽히는 캡션 + 기존 "국립" 검색 더보기.
- 추천: 2열 반응형 포스터 그리드(제목·장소 하단), 국립 갤러리와 형태가 다름. 홀수·좁은 화면에서도 잘리지 않음.
- 섹션 제목은 Hahmlet, 보조는 Pretendard, 기존 팔레트만 사용.

## Constraints

- 기존 데이터 훅·중복 제거(`featuredTrioIds`)·라우트(`/(explore)/{id}`, `/search?q=국립`)·인증 유지.
- 로딩/에러(다시 시도)/빈 상태 동작 유지. 이미지·장소 없음은 정직한 플레이스홀더.
- 순위 번호·통계·소셜 프루프·개인화 주장·가격·신규 API 필드 금지. 신규 의존성/백엔드/커밋 없음.
- 공용 카드(`KcisaExhibitionCard`, `PopularExhibitionAvatar`, `HorizontalSection`, `SectionTitle`) 수정 금지(다른 화면 영향).

## Non-goals (out of scope)

- 상단 헤더·검색·히어로·FAB, `useExploreScreenData` 등 데이터 로직, 다른 탭, `skills-lock.json` 등 기존 더티 변경.

## Users & context

- 홈 탭 진입 전체 사용자(로그인/비로그인).

## Acceptance criteria

### AC-1: 인기 전시 에디토리얼 컬렉션

- **Given** 중복 제거된 인기 전시가 1개 이상
- **When** 홈을 스크롤한다
- **Then** 둥근 톤온톤 컨테이너 안에 포스터 썸네일·상태·제목(2줄)·장소가 있는 행이 헤어라인으로 구분되어 보이고, 원형 아바타·순위 번호가 없으며, 행을 누르면 상세로 이동한다.

### AC-2: 국립 기관 톤온톤 갤러리

- **Given** 국립 기관 캐러셀 데이터(또는 로딩/에러/빈 상태)
- **When** 섹션을 본다/가로 스크롤한다
- **Then** 풀블리드 웜 톤 밴드에 큰 세로 포스터와 상태·제목·장소 캡션이 보이고 번호 오버레이가 없다. "더보기"는 `/search?q=국립`으로 이동. 기존 섹션 숨김 조건과 로딩/에러/빈 상태 유지.

### AC-3: 추천 2열 포스터 그리드

- **Given** 추천 목록(홀수 포함)
- **When** 화면 폭이 달라진다(작은 폰 포함)
- **Then** 폭 기반 2열로 포스터 아래에 제목·장소가 보이고, 홀수 마지막 셀은 빈 칸으로 남아도 잘리거나 늘어나지 않는다. 제목은 개인화 여부에 따라 기존 규칙(`name님을 위한 추천` / `추천 전시`)을 유지한다.

### AC-4: 통합 · 회귀

- **Given** 변경된 홈
- **When** 각 섹션 카드 1개를 눌러 상세→뒤로, 더보기, 상단 히어로 확인
- **Then** 모두 정상. tsc/test/format 통과.

## Risks & dependencies

- 이미지 없는 전시는 `ImageFallback` 질문 아이콘(정직한 placeholder).
