# Spec — 홈 캐러셀 하단 전면 리디자인 (랭킹 + 매거진)

## Problem

- 직전 `home-discovery-sections`의 하단 3섹션(톤온톤 리스트 · 웜 밴드 갤러리 · 2열 그리드)은 정보가 제목·장소·상태뿐이라 "왜 지금 봐야 하는지"가 없다.
- 섹션 리듬이 비슷해 스크롤 동기가 약하다 → 이탈 위험.
- 앱의 핵심 기능(AI 도슨트)으로 이어지는 진입점이 FAB 하나뿐이다.

## Goals

- 섹션마다 형태가 다른 매거진 리듬 + "지금 봐야 할 이유"(순위, 마감 D-day, 기간)를 실제 데이터로 제시.
- 앱 기능(AI 도슨트)을 맛보게 하는 "오늘의 명화" 진입점.
- 웜뉴트럴 팔레트 · Hahmlet/Pretendard 유지.

## 데이터 근거 (지어내지 않음)

| 표시          | 근거                                                                                                                 |
| :------------ | :------------------------------------------------------------------------------------------------------------------- |
| 인기 순위 1~5 | `get_popular_exhibitions` RPC (북마크+조회 점수) 정렬 순서                                                           |
| D-day / 기간  | `exhibitions.start_date`/`end_date` (culture·kcisa·popular·recommended 쿼리가 이미 조회)                             |
| 오늘의 명화   | 정적 큐레이션 Met objectID 13개(2026-10-07 curl로 존재·퍼블릭도메인·이미지 확인) + Met Object API로 이미지·연도 조회 |

## Constraints

- 기존 라우트(`/(explore)/{id}`, `/search?q=국립`), 중복 제거(`featuredTrioIds`), 로딩/에러/빈 상태 유지.
- 신규 의존성·백엔드 변경·커밋 없음. 공용 컴포넌트(`ExhibitionStatusBadge`, `ImageFallback` 등) 수정 금지.
- 명화 이미지 실패 시 조용히 폴백(텍스트 카드 유지), 해설 진입은 FAB와 동일한 로그인·프리미엄 게이트.

## Non-goals

- 상단 헤더·검색·캐러셀·FAB, 다른 탭, `skills-lock.json` 등 기존 더티 변경.

## 섹션 순서

캐러셀 → **AC-1 인기 TOP 5** → **AC-2 곧 막을 내려요** → **AC-3 오늘의 명화** → **AC-4 추천 매거진** → **AC-5 국립 기관**

## Acceptance criteria

### AC-0: 날짜 메타 유틸

- Given 전시의 start/end 날짜 When 메타를 계산하면 Then 진행 중 ≤14일은 `D-n`/`오늘 마감`, 예정은 `M.D 개막`, 그 외 진행 중은 `~M.D`를 반환한다. 날짜 없음/형식 오류는 `null`.
- Given 여러 소스 목록 When 마감 임박을 뽑으면 Then 진행 중·0~14일 남은 전시를 마감 순으로, 제외 ID·중복 ID를 빼고 최대 N개 반환한다.

### AC-1: 인기 TOP 5 랭킹

- Given 인기 데이터 When 홈을 보면 Then 큰 Hahmlet 순위 숫자 + 썸네일 + 제목 + 장소 + 기간/D-day가 행으로 보이고, 1~3위는 진한 숫자로 강조된다.
- Given 행 탭 When Then `/(explore)/{id}` 이동. 로딩=스켈레톤, 에러=다시 시도, 빈 상태=문구.

### AC-2: 곧 막을 내려요

- Given 14일 이내 마감 전시가 있으면 Then 포스터 위 `D-n` 칩이 붙은 가로 레일이 보인다. 캐러셀·인기와 중복된 전시는 빠진다.
- Given 대상이 0건 When 로딩 완료 Then 섹션을 숨긴다. 에러면 조용히 숨긴다(다른 섹션이 같은 소스의 에러를 이미 표시).

### AC-3: 오늘의 명화

- Given 날짜 When 홈을 보면 Then 날짜 기반으로 고정 선택된 명화 1점이 다크 밴드에 이미지·한국어 제목·작가·연도와 "AI 도슨트 해설 듣기" 버튼으로 보인다.
- Given 이미지 조회 실패 Then 플레이스홀더로 폴백하고 버튼은 동작한다.
- Given 버튼 탭 Then 비로그인=로그인 유도, 비프리미엄=`/settings/premium`, 프리미엄=스토어에 작품 정보를 넣고 `/(guide)/description`으로 이동.

### AC-4: 추천 매거진

- Given 추천 목록 Then 첫 항목은 전폭 대형 카드(이미지 위 그라데이션 + 제목·장소·기간), 나머지는 2열 카드로 보인다. 홀수 나머지는 한 칸만 채운다.
- 개인화 제목(`{name}님을 위한 추천`) 유지. 로딩/에러/빈 상태 유지.

### AC-5: 국립 기관

- Given 국립 목록 Then 첫 항목은 와이드(16:10) 커버 카드, 나머지는 작은 정사각 카드 가로 레일. "전체" → `/search?q=국립`.
- 기존 숨김 조건(히어로가 kcisa이고 표시할 항목 없음) 유지.
