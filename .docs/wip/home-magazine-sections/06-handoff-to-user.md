# Handoff

캐러셀 아래를 사용자 피드백 8차에 걸쳐 정리한 최종 구성: **캐러셀 → 곧 막을 내려요 → (개인화 사용자만) 추천 → 오늘의 명화**. 단계별 변경 이력은 `04-dev-notes.md`.

## 최종 구성

| 섹션           | 내용                                                                               |
| :------------- | :--------------------------------------------------------------------------------- |
| 곧 막을 내려요 | 1~14일 남은 전시 D-day 포스터 레일(마감일 당일 제외), 전체 → 검색 '마감 임박' 필터 |
| 추천           | 선호 장르가 있는 사용자에게만 2×2 그리드                                           |
| 오늘의 명화    | Met 퍼블릭 도메인 73점, 해설을 들은 다음 날에만 다음 그림                          |

함께 반영: 검색 '마감 임박' 필터(배지 숨김·예정/진행 중 칩 숨김), Met 검색 v1.1 이관, 상세 D-day `D-D-n` 수정.

## 미검증 (사용자 확인 필요)

1. 비로그인·비프리미엄 계정의 명화 CTA 분기, 다음 날 명화 전환(단위 테스트로만 검증).
2. 추천 그리드 D-day 회색 변경·검색 칩 숨김의 시뮬레이터 화면 확인(시뮬레이터에 다른 앱이 떠 있어 미실행).

## 2차 리뷰에서 보고만 한 항목 (수정 안 함)

- 캐러셀 빈 상태에 다시 시도 없음, `px-6`(≈21px)과 24px 상수의 3px 정렬 차이, 자정 경과 시 날짜 라벨·마감 레일 갱신 지연.
- `useExploreScreenData`의 홈 미사용 반환값, D-day 계산이 `exhibitionSearch`와 중복, `getMetObjectImage`의 조회 코드 반복.
- `app/search.tsx`의 기존 부정 조건 중첩 삼항(§11.1·§11.2).
