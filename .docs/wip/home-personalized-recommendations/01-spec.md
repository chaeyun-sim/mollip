# Spec — 홈 취향 추천 재디자인

## Problem

사용자가 홈의 맞춤 추천 영역 디자인을 마음에 들어 하지 않아 렌더링을 주석 처리했다. 기존 목차형 행은 바로 위 출발 안내판과 유사하다. 선호 장르 결과가 없을 때 일반 전시가 대체될 수 있어 맞춤 추천 문구와 실제 데이터가 어긋날 수 있다.

## Goals

- 추천 영역을 앞의 포스터 그리드·출발 안내판과 구별되는 편집 카드로 재디자인한다.
- 선호 장르와 실제 일치하는 전시가 있을 때만 홈에 노출한다.
- 상세 이동과 접근성 라벨을 유지한다.

## Constraints

- 사용자가 주석 처리한 영역을 기반으로 작업한다. 다른 홈 섹션과 기존 작업 트리 변경은 보존한다.
- 개인화 결과가 없으면 일반 전시를 ‘취향 맞춤’으로 표시하지 않는다.

## Non-goals (out of scope)

- 추천 점수 모델·취향 설정 플로우 변경
- 홈 상단 추천 그리드와 출발 안내판 재디자인

## Acceptance criteria

### AC-1: 추천 데이터 조건

- **Given** 사용자가 선호 장르를 설정한 상태
- **When** 해당 장르에 맞는 추천 결과가 있으면
- **Then** 다른 홈 섹션에 이미 나온 전시를 제외해 추천 섹션을 보이고 상세로 이동한다.
- **Given** 선호 장르가 없거나 일치 결과가 없는 상태
- **When** 홈이 렌더링되면
- **Then** 맞춤 추천 섹션을 숨긴다.

### AC-2: 시각 위계

- **Given** 추천 섹션이 표시되는 상태
- **When** 사용자가 홈을 스크롤하면
- **Then** 포스터를 곁들인 편집 카드가 출발 안내판과 구별되고 긴 제목·이미지 실패에도 정보가 읽힌다.

## Screens / routes

| Route     | 변경                                 |
| --------- | ------------------------------------ |
| `/(tabs)` | 개인화 추천 영역 재노출·새 카드 적용 |

## Risks & dependencies

실제 로그인 계정의 선호 장르와 추천 API 결과에 따라 시뮬레이터에서 섹션이 보이지 않을 수 있다. 그 경우 조건 검증과 별도 시안 렌더링 증빙을 구분한다.
