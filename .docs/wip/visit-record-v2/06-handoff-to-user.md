# Handoff — 기록하기

다이어리 FAB '기록하기' → ① 고르기(도슨트·스크랩 추천 / 검색 / 직접 기록) → ② 기록(방문일·동행으로 탑승권이 채워짐 + 도장 별점·사진·키워드·영감 한 줄) → 도장 쿵 → 다이어리. (체크인 화면은 사용자 피드백으로 기록 화면에 합침)

증빙: `05-qa-report.md`, `evidence/`. 저장 이후 흐름은 실제 기록이 생겨 시뮬레이터에서 실행하지 않았다 — 직접 한 번 남겨 확인 부탁.

## 피드백 반영 — 직접 기록

직접 기록 패널을 모달 바텀시트로 옮겼다. 검색어로 시트를 열면 전시 이름이 미리 채워지고, 닫기 버튼과 제출 뒤 기록 화면 이동이 동작한다. 검색 결과가 없을 때 표시되는 기존 조건은 유지했다. 시트 입력은 바텀시트 키보드 동작을 사용하고 각 입력 및 버튼에 접근성 이름을 제공한다.

확인: `npx tsc --noEmit`, 41개 테스트 스위트 / 307개 테스트, iPhone 17 Pro 시뮬레이터에서 열기·닫기·제출 확인. 캡처는 `evidence/manual-sheet-open.png`, `evidence/manual-sheet-submit-result.png`.
