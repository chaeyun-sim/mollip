# Design brief — 기록하기

## Design intent

- 홈의 출발 안내판·탑승권 이야기를 기록으로 잇는다: 고르고 → **탑승권이 채워지고** → **도장이 찍힌다**.
- 폼이 아니라 "티켓을 완성하는" 감각. 입력은 칩 위주, 키보드는 최소.

## Tokens

- 배경 `bg-bg-light`, 카드 `bg-white` / `bg-bg-tonal`, 잉크 `gray900`, 보조 `gray600/700`
- 선택 상태: `bg-gray900` + `text-white` 칩, 강조 `primary-dark`(도장·별점)
- Pretendard 위주, Hahmlet은 탑승권 전시명 한 곳

## Screens

| 화면                             | 구성                                                                                                                                                                                                   |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ① 고르기 `/diary/record`         | 헤더 '기록하기' + `1/3` · "어떤 전시를 보셨나요?" · 검색바 · (검색어 없음) 도슨트로 다녀온 전시 / 스크랩한 전시 행 · (검색어) 진행 중·지난 전시 탭 + 결과 행 · 하단 '직접 기록하기' 행 → 전용 바텀시트 |
| ② 체크인 `/diary/record/checkin` | 탑승권 미리보기(왼쪽 포스터 스텁 + 절취선 + 전시명 / DATE · GATE · WITH 칸, 빈 칸은 `—`) · "언제 다녀왔나요?" 칩 · "누구와 함께했나요?" 아이콘 칩 6 · 하단 '다음'                                      |
| ③ 기록 `/diary/record/write`     | 미니 탑승권 · 도장 별점 5 + 한 줄 캡션 · 사진 3칸(작품·공간·나) · 감각 키워드 칩 · 영감 한 줄(대상 칩 + 100자 입력) · 하단 '기록 남기기' → 도장 쿵                                                     |

## States

- 검색 로딩: 결과 자리 스켈레톤 3행 / 결과 없음: 직접 기록 행만
- 추천 없음: 추천 섹션 숨김, 검색 안내 문구
- 저장 실패(사진 업로드): Alert 후 화면 유지

## Accessibility

- 칩은 `accessibilityState={{ selected }}`, 도장 별점은 "별점 N점"
- 터치 타깃 44pt 이상, 하단 버튼 disabled 시 `accessibilityState.disabled`
- 직접 기록은 바텀시트 전용 입력 컴포넌트와 개별 접근성 라벨을 사용하고, 시트 컨테이너는 자식 컨트롤을 가리지 않도록 접근성 트리에서 제외한다.
