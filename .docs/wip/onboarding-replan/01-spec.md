# Spec — 온보딩 "나의 첫 전시 벽" 드래그 배치 재설계

## Problem

- 현재 `app/onboarding/index.tsx`와 `useOnboardingWallFlow`는 프롤로그 뒤 5개 트레이를 순서대로 보여주며 트레이마다 3개 작품 중 하나를 탭하게 한다. 전체 벽을 직접 꾸미는 경험이 부족하다.
- 새 방향은 하나의 갤러리 벽에서 빈 액자 5개와 작품 트레이를 함께 보여주고, 작품을 드래그해 원하는 액자에 거는 경험이다. 탭은 동등한 접근성 대안으로 제공한다.
- 기존 초안에는 후보 15~20개와 장르당 작품 1개 조건, 이미 확보된 에셋을 미확보로 설명한 부분이 충돌했다. 현재 `assets/images/genres/`에 최종 후보 16개 파일이 모두 확보되어 있으며, 현대 미술 4개는 사용자가 제공한 로고 재해석 이미지다.
- 설치·미디어 등을 제외하지 않고 온보딩의 ‘현대 미술’ 취향으로 통합한다. 앱 전역 전시 분류 체계는 유지한다.

## Goals

- 비대칭으로 배치된 액자 5개(타원형 2개, 사각형 3개)가 있는 단일 벽 화면을 제공한다.
- 7개 취향 장르의 총 16개 이미지를 선택 후보로 사용한다. 현대 미술은 설치·미디어·큐비즘·초현실주의를 재해석한 로고 4개로 폭넓게 보여주며 나머지 장르는 각 2개다.
- 드래그 또는 탭만으로 배치·교체·완료할 수 있게 한다.
- 액자 3개 이상을 채우면 ‘이 전시로 시작하기’를 활성화한다. 최대 배치는 5개다.
- 완료 시 배치 작품의 장르 요약을 보여주고 기존 진입 경로별 저장·실패 처리 계약을 유지한다.
- 설정의 ‘내 취향 수정’에서는 기존 장르 취향을 대표 작품으로 복원해 시작한다.

## Constraints

### 화면과 에셋

- 프롤로그는 유지하고, 이후 순차 트레이와 별도 선택 확인 화면을 갤러리 벽 및 비차단 장르 요약으로 대체한다.
- 벽과 트레이를 같은 화면에 둔다. 16개 썸네일을 한꺼번에 억지로 축소하지 않고 트레이를 스크롤할 수 있게 한다. 벽·CTA가 가려지지 않는 배치와 스크롤/드래그 제스처 구분은 Sam이 브리프에 명시한다.
- `assets/images/onboarding/wall-bg.png`(1536×1024)와 아래 액자 에셋은 이미 존재한다. 신규 생성이나 외부 작품 검색은 선행 조건이 아니다.

| 액자 ID / 파일 | 원본 치수 | 형태 |
| -------------- | --------- | ---- |
| `oval-1.png`   | 275×424   | 타원 |
| `oval-2.png`   | 229×371   | 타원 |
| `square-1.png` | 296×231   | 사각 |
| `square-2.png` | 366×476   | 사각 |
| `square-3.png` | 343×288   | 사각 |

- 액자는 대/중/소 그룹으로 묶지 않는다. 원본 종횡비와 액자별 상대 크기를 보존하되 화면에 맞춘 공통 비율 축소는 허용한다. 원본 픽셀 수를 화면의 논리 크기로 강제하지 않는다.
- 좌우 대칭 계단식이 아닌 비대칭 자유 배치를 사용한다. 좌표, 액자 안쪽 마스크, 작품별 크롭과 드롭 영역은 Sam이 실제 에셋에 맞춰 정의한다. 액자 장식 위에 작품이 덮이지 않아야 한다.
- `.docs/DESIGN_SYSTEM.md`와 `.docs/rules/component-convention.md`를 따른다. 기존 `.claude/rules/component-convention.md` 참조는 현재 정본 경로로 대체한다.
- 기존 Reanimated/Gesture Handler를 활용하고 신규 애니메이션 라이브러리는 추가하지 않는다.

| 조각      | `조각`     | `skulpture-thinking-vertical.jpg`      | `skulpture-pieta-square.jpg`                                                                |
| 판화      | `판화`     | `print-wave-horizontal.jpg`            | `print-melencolia-vertical.jpg`                                                             |

- 최종 후보 16개는 모두 로컬 폴더에서 파일 존재를 확인했다. 현대 미술 4개는 원작 도판 대신 로고 재해석 이미지를 사용한다. 사용자가 밝힌 교체 이유는 저작권 우려다.
- 현대 미술의 세부 콘셉트는 아래 사용자 설명을 기준으로 한다. 작가명은 내부 스타일 참고이며 해당 작가의 실제 작품이나 공식 로고로 표시하지 않는다.

| 후보   | 파일                            | 사용자 지정 콘셉트                        |
| ------ | ------------------------------- | ----------------------------------------- |
| 현대 1 | `contemporary-1-horizontal.png` | 바나나를 테이프로 붙인 설치 콘셉트의 로고 |
| 현대 2 | `contemporary-2-vertical.png`   | 백남준 풍의 미디어아트 로고               |
| 현대 3 | `contemporary-3-square.png`     | 피카소 풍의 큐비즘 스타일 로고            |
| 현대 4 | `contemporary-4-horizontal.png` | 달리 스타일의 로고(초현실주의 콘셉트)     |

- 네 이미지 모두 저장 장르는 `현대미술`이다. 현대 3·4도 기존 `회화` 장르로 옮기지 않는다. 세부 콘셉트는 현대 미술 취향의 폭을 보여주는 내부 설명이며 별도 저장 장르를 만들지 않는다.
- 작품마다 고유 `id`, 로컬 이미지 참조, 저장용 `genre`, 인상/감상 단서가 있는 접근성 라벨을 둔다. 현대 미술 후보는 4개, 나머지 장르는 각 2개이며 **프리필 기본 대표는 장르당 1개**만 지정한다.
- 조각·공예도 제공된 사진 이미지를 작품으로 사용한다. 작품 원본이 평면 매체인지 여부로 후보를 제외하지 않는다.
- 최종 16개 이미지의 세부 감상 라벨과 크롭은 Sam이 실제 이미지를 보고 브리프에서 확정한다. 이 문서는 파일 존재와 분류를 기준으로 하며 이미지별 출처·라이선스 검증 완료를 의미하지 않는다.

### 온보딩 장르 통합 규칙

선택 작품의 장르, 완료 요약, 기존 취향 프리필은 동일한 온보딩용 정규화 규칙을 사용한다.

| 입력 장르                                   | 온보딩 저장 값 | UI 표기       |
| ------------------------------------------- | -------------- | ------------- |
| 사진·조각·판화·한국화·회화·공예             | 각각 유지      | 각각 유지     |
| 현대미술·설치·미디어아트·영상·사운드·팝아트 | `현대미술`     | 현대 미술     |
| 드로잉                                      | `회화`         | 회화          |
| 섬유                                        | `공예`         | 공예          |
| 그래픽                                      | `판화`         | 판화          |
| 위 목록에 없는 값                           | 제외           | 표시하지 않음 |

- 설치·미디어아트·영상·사운드·팝아트를 ‘현대 미술’로 묶는 것은 사용자 요청을 반영한 취향 그룹이다. 각 세부 매체의 별도 이미지 확보는 필수가 아니다.
- 드로잉→회화, 섬유→공예, 그래픽→판화는 나머지 기존 취향도 버리지 않기 위한 이번 기획의 기본 매핑이다. 미술사적 동치 관계를 뜻하지 않는다.
- `ART_GENRE_VALUES`/`ART_GENRE_RULES`, DB 스키마, 전시 검색·분류·추천 로직은 변경하지 않는다. 저장할 때는 통합된 canonical 값에 기존 `toValidGenres` 검증과 중복 제거를 적용한다.
- 예: 기존 `[설치, 미디어아트, 사진]`은 `[현대미술, 사진]`으로 프리필한다. 사용자가 저장하기 전에는 서버 값을 수정하지 않는다.

### 배치와 상태 규칙

- 액자 순서는 `oval-1 → oval-2 → square-1 → square-2 → square-3`으로 고정해 접근성 탐색, 동률 처리, 프리필, 장르 요약 순서에 사용한다. 시각적 좌표는 Sam이 정한다.
- 작품 하나는 벽에 한 번만 배치한다. 같은 장르의 서로 다른 작품은 함께 배치할 수 있다. CTA 기준은 장르 수가 아닌 채워진 액자 수다.
- 배치된 작품은 트레이에서 위치를 유지하며 ‘배치됨’ 상태로 표시하고 중복 배치 동작을 비활성화한다. 교체·제거되면 다시 선택 가능해진다.
- 트레이 작품→빈 액자는 배치, 트레이 작품→채워진 액자는 교체, 액자→빈 액자는 이동, 액자→채워진 액자는 맞교체다. 자기 액자에 놓으면 변화가 없다.
- 탭 배치는 탭한 썸네일 중심과 빈 액자 중심 사이의 화면 좌표 거리로 가장 가까운 곳을 고른다. 동률이면 고정 액자 순서를 따른다. 교체 대상 액자를 먼저 선택했다면 그 대상이 우선한다.
- 채워진 액자를 탭하면 교체 대상이 된다. 미배치 작품을 탭하면 교체하고 선택 상태를 해제한다. ‘취소’는 원래 배치를 유지하고, ‘작품 빼기’는 대상 액자를 비운다. 전체가 찼는데 대상 없이 트레이를 탭하면 변경 없이 ‘바꿀 액자를 먼저 선택해 주세요’를 안내한다.
- 드래그 실패·취소는 출발 위치로 복귀한다. 프레임에서 시작했다면 프레임으로, 트레이에서 시작했다면 트레이로 돌아가며 배치를 잃지 않는다.
- 요약·저장 중에는 배치 편집과 완료 중복 실행을 막는다. 실패 시 선택은 유지한다.

## Non-goals (out of scope)

- 확보된 16개 외의 새 작품 소싱, Wikidata/Commons 검색, 로고 재해석 이미지 생성, 제공 파일의 이름 변경.
- 앱 전역의 장르 통합, 추천 알고리즘 변경, DB 마이그레이션, 작품 ID·액자 좌표의 서버 저장.
- 프롤로그 카피, 로그인·약관 및 온보딩 전후의 다른 화면 개편.
- 장식 인물·실루엣 추가, 액자 개수 변경, 액자 자체를 사용자가 이동·확대하는 편집 기능.
- 기획 작성 후 사용자 지시로 Sam의 디자인 단계 착수가 승인되었다. 구현·QA는 후속 파이프라인 게이트를 따른다.

## Users & context

- 신규 사용자: 기존 프롤로그 이후 5개 액자가 모두 빈 상태로 시작한다.
- 기존 사용자: 설정의 ‘전시 벽 다시 꾸미기’에서 프롤로그를 생략하고 저장된 취향을 대표 작품으로 프리필한다. 기존 저장 스키마에 작품 ID가 없으므로 이전 작품·배치를 그대로 복원하는 기능은 아니다.

## Acceptance criteria

### AC-1: 3개 액자 채움 시 CTA 활성화

- **Given** 벽에 작품이 0~2개 배치되어 있다.
- **When** 드래그 또는 탭으로 세 번째 액자를 채운다.
- **Then** ‘이 전시로 시작하기’가 활성화된다. 같은 장르 작품도 각각 채움 수에 포함하며, 제거 후 2개 이하가 되면 다시 비활성화된다.

### AC-2: 최대 5개 및 작품 중복 배치 방지

- **Given** 액자 5개가 모두 찼거나 특정 작품이 이미 배치되어 있다.
- **When** 트레이에서 추가 배치를 시도한다.
- **Then** 여섯 번째 액자나 같은 작품의 복제는 생기지 않는다. 미배치 작품은 명시적으로 겨냥한 액자에만 교체할 수 있고, 대상 없는 탭은 교체 대상 선택 안내만 표시한다.

### AC-3: 빈 액자에 드래그 배치

- **Given** 미배치 작품과 빈 액자가 있다.
- **When** 작품을 해당 액자의 드롭 영역에 놓는다.
- **Then** 해당 액자에 작품이 배치된다. 액자 원본 종횡비를 유지하고 작품은 액자 안쪽 형태에 맞춰 표시된다.

### AC-4: 드래그 중 대상 피드백

- **Given** 작품 드래그가 시작되었다.
- **When** 드래그가 진행되거나 액자 위에 진입한다.
- **Then** 빈 액자들은 강조되고 현재 드롭 대상은 구분된다. 교체·맞교체 대상도 식별 가능하며 종료·취소 시 강조가 해제된다.

### AC-5: 트레이에서 드래그해 교체

- **Given** 채워진 액자와 미배치 트레이 작품이 있다.
- **When** 트레이 작품을 해당 액자에 놓는다.
- **Then** 기존 작품 대신 새 작품이 배치되고 채움 수는 유지된다. 기존 작품은 트레이에서 다시 선택 가능해진다.

### AC-6: 탭만으로 배치·완료

- **Given** 빈 액자가 있고 교체 대상으로 선택된 액자는 없다.
- **When** 미배치 썸네일을 탭하거나 스크린 리더로 활성화한다.
- **Then** 정의된 거리·동률 규칙으로 빈 액자에 배치한다. 드래그 없이 3개 이상 채우고 완료할 수 있다.

### AC-7: 탭으로 교체·제거·취소

- **Given** 채워진 액자가 있다.
- **When** 해당 액자를 탭하고 미배치 작품 선택, ‘작품 빼기’, ‘취소’ 중 하나를 실행한다.
- **Then** 각각 해당 액자 교체, 비우기, 기존 상태 유지가 적용되고 선택 상태가 해제된다. 모든 동작은 스크린 리더로도 실행 가능하다.

### AC-8: 유효하지 않은 드롭·제스처 취소

- **Given** 트레이 또는 액자에서 작품을 드래그하고 있다.
- **When** 액자 밖에 놓거나 제스처가 취소된다.
- **Then** 원래 출발 위치로 복귀하고 배치 상태·채움 수는 변하지 않는다. 동작 줄이기 설정에서는 이동 애니메이션을 축소하거나 생략한다.

### AC-9: 16개 로컬 작품과 장르 통합

- **Given** 확보된 16개 로컬 에셋으로 갤러리 벽이 초기화된다.
- **When** 전체 트레이 데이터 및 장르 정규화를 확인한다.
- **Then** 목록의 16개 로컬 파일이 중복 없이 포함된다. 현대 미술에는 지정된 로고 4개(바나나 테이프 설치·백남준 풍 미디어아트·피카소 풍 큐비즘·달리 스타일), 나머지 6개 장르에는 각 2개 후보가 있으며 기본 대표는 장르당 1개다. 로고 4개의 저장 값은 모두 `현대미술`이다. 설치·미디어아트·영상·사운드·팝아트는 `현대미술`로 통합되며 나머지 입력도 매핑 표를 따른다. 외부 이미지 검색 없이 후보를 표시한다.

### AC-10: 접근성 라벨과 상태 안내

- **Given** 스크린 리더 사용자가 트레이나 액자에 포커스한다.
- **When** 항목을 탐색하고 배치·교체·제거한다.
- **Then** 작품에는 ‘인상/감상 단서 + UI 장르’ 라벨, 액자에는 번호와 빈 상태/작품 정보, 버튼에는 역할과 비활성·선택 상태가 제공된다. 완료 동작 후 ‘현대 미술 작품을 걸었어요. 3/5’처럼 결과와 채움 수를 안내한다. 매 프레임 드래그 위치는 반복 공지하지 않는다. 조작 영역은 최소 44×44 논리 단위를 확보하고 포커스가 사라지지 않는다.

### AC-11: 비차단 장르 요약

- **Given** 3~5개 액자를 채웠다.
- **When** ‘이 전시로 시작하기’를 누른다.
- **Then** 고정 액자 순서로 작품 장르를 정규화·중복 제거해 요약한다. `현대미술`은 ‘현대 미술’로 표시하고 약 1.5초 노출 후 별도 확인 없이 저장을 한 번 실행한다. 스크린 리더에도 요약을 공지하며 저장 중 같은 요약을 유지한다. 화면 이탈로 예약된 저장이 뒤늦게 시작되지 않도록 정리한다.

### AC-12: 진입 경로별 기존 저장 계약 보존

- **Given** 요약 후 저장을 시작한다.
- **When** 저장 성공, 실패, 재시도 또는 무저장 진행이 발생한다.
- **Then** 정규화한 장르를 `toValidGenres`로 검증·중복 제거한 뒤 아래 계약을 따른다. 오류 시 배치와 요약을 유지하고 `OnboardingSaveErrorBar`의 재시도·무저장 동작을 제공한다.

| 경로        | 성공                                                                  | 실패·재시도                                                 | 무저장 진행                                   |
| ----------- | --------------------------------------------------------------------- | ----------------------------------------------------------- | --------------------------------------------- |
| 최초 온보딩 | `preferred_genres`와 `onboarding_completed` 갱신, 기존 완료 경로 진행 | 사용자별 `setPendingGenres` 레코드 보존, 같은 장르로 재시도 | 기존 로컬 완료·이후 pending 동기화 계약 유지  |
| 설정 재편집 | `preferred_genres`만 갱신 후 기존 복귀 경로 진행                      | 새 온보딩 pending을 만들지 않고 선택 유지·재시도            | 서버 취향을 변경하지 않고 기존 복귀 경로 진행 |

- 두 경로 모두 `preferred_artists`를 변경하지 않는다. 설정의 ‘내 취향 지우기’도 기존 계약을 유지한다.

### AC-13: 액자 간 이동·맞교체

- **Given** 액자 A에 작품이 있고 다른 액자 B가 있다.
- **When** A의 작품을 B로 드래그한다.
- **Then** B가 비어 있으면 작품을 이동해 A가 비고, B가 채워져 있으면 두 작품을 맞교체한다. 두 경우 모두 총 채움 수는 유지된다. A에 다시 놓으면 변화가 없다.

### AC-14: 기존 취향 프리필

- **Given** 사용자가 설정에서 ‘전시 벽 다시 꾸미기’로 진입한다.
- **When** 저장된 `preferred_genres`를 읽어 벽을 초기화한다.
- **Then** 저장 순서를 유지하며 매핑→미지원 값 제외→중복 제거→앞 5개 선택 순으로 처리하고, 각 장르의 기본 대표 작품을 고정 액자 순서로 배치한다. 남은 액자는 비운다. 예를 들어 `[설치, 미디어아트, 사진]`은 현대미술·사진 대표 작품 2개를 배치하며 CTA는 비활성이다.
- **Then** 빈 취향은 빈 벽으로 시작한다. 불러오기 중에는 편집을 잠가 늦은 응답이 사용자 편집을 덮지 않게 하고, 조회 실패는 빈 취향으로 간주하지 않고 재시도를 제공한다. 프리필 자체는 저장을 실행하지 않는다.

## Risks & dependencies

- **제스처**: 스크롤과 드래그의 충돌, 좌표계 변환, 타원 마스크와 드롭 영역, 트레이/액자 출발 구분을 검증해야 한다. Sam이 제스처 시작 기준과 히트 영역을 브리프에서 정의한다.
- **에셋**: 최종 16개와 벽·액자의 파일 존재를 확인했고 에셋 인수 대기는 해소되었다. 현대 미술 콘셉트는 사용자 설명으로 확정했다. 실제 이미지별 방향·크롭·시각적 통일감과 접근성 감상 문구는 디자인 검토 대상이다. 파일명만으로 작품 정보나 사용권을 단정하지 않는다.
- **프리필 정보 손실**: 서버에 장르만 저장하므로 같은 장르의 추가 후보를 골라도 재진입 시 기본 대표로 표시된다. 장르 통합으로 프리필이 3개 미만이면 추가 배치가 필요하다.
- **추천 범위**: 이번 작업은 온보딩 취향 그룹만 바꾼다. `현대미술` 저장이 설치·미디어 전시 추천까지 자동 확장됨을 보장하지 않는다.
- **접근성**: Taylor는 스크린 리더의 탐색·교체·제거·완료를 검증한다. 실기기 접근성 검증을 수행할 환경이 없으면 미검증 항목으로 명시한다.
- **티어 L**: 순차 탭에서 동시 드래그로 상호작용·상태 머신·데이터 구조를 바꾸므로 전체 디자인 검수 및 프로토타입 시뮬레이터 게이트가 필요하다.
