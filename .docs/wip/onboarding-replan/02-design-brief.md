# Design brief — 나의 첫 전시 벽

## Design intent

16개의 이미지를 둘러보고 다섯 개의 실제 금빛 액자를 채우는 작은 갤러리다. 벽이 주인공이고 트레이와 안내는 단정한 크림색 표면으로 낮춘다. 타원 2개와 사각 3개를 원본 크기 비율 그대로 비대칭 배치한다. 현대 미술의 로고 네 개도 다른 이미지와 동일한 작품 후보로 취급한다.

G1 Pass된 `01-spec.md`를 인수했다. 2026-09-13 Sam이 `view_image`로 작품 16개, 액자 5개, 벽 배경을 개별 열람했다. 신규 이미지 생성은 필요하지 않다. 사용자 요청에 따라 Codex Manager가 Alex 검수 역할을 맡았다. 검수 결과는 `03-design-review.md`에 별도 기록하며 앱 구현·QA와 구분한다.

## Tokens (defaults)

- 배경 `bg-gray100` #F8F6F2, 트레이 `bg-gray200` #F2EFE9, 본문 `text-gray900` #1C1917, 설명 `text-gray700` #57534E, 구분선 `border-gray300` #E7E5E4.
- 활성 CTA `bg-primary-dark text-white`, 비활성 `bg-gray400 text-white`. **실제 정본 `tailwind.config.js`의 primary-dark는 #7C3AED, primary는 #AB77F1**이다. DESIGN_SYSTEM의 예전 브랜드 팔레트 표(#625876/#81759B)와 다르므로 정본 우선 규칙을 따른다. 이번 디자인에서 토큰 자체는 변경하지 않는다.
- 포커스는 디자인 시스템의 `border-primary`를 유지하되 바깥에 gray900 1pt 보조선을 추가하고 밝은 매트 위에 표시한다. 현재 primary/gray100 대비는 2.93:1, primary/gray200은 2.76:1이므로 primary 선만으로 식별하지 않는다. gray900 보조선·선택 문구를 함께 사용한다. 드롭 가능 여부는 색상만으로 전달하지 않는다.
- 제목 Hahmlet SemiBold 24/34, 본문 Pretendard Regular 14/21, 작품 장르 Pretendard Medium 12/18, CTA Pretendard SemiBold 16/24. 상태 카운트 14/20. 글자 크기 확대를 허용한다.
- 좌우 패딩 20pt, 구획 간격 12/16pt, 트레이 카드 radius 12pt, CTA radius 18pt. 액자 이미지 자체에 라운드·회전·색 보정을 적용하지 않는다.
- 고정값·폰트는 NativeWind className, 조건부 className은 `cn`. 계산 좌표·safe area·transform만 style 허용. Props interface, named export, 외부/내부 두 import 블록 등 component-convention 정본을 준수한다.

### 화면 크기와 벽 좌표

화면의 usable height U는 위·아래 safe area를 뺀 높이다. `Screen` 기본 px-5를 중복 적용하지 않는다. 콘텐츠 폭 W = min(화면 폭 - 40, 560), 중앙 정렬. CTA 영역은 `paddingBottom: insets.bottom + 12`로 홈 인디케이터와 분리하고 safe area를 이중 차감하지 않는다.

높이 계산은 U에서 시작하므로 CTA 예산에는 버튼 52 + 상하 24만 차감하고 insets.bottom은 다시 차감하지 않는다. 실제 렌더링의 bottom padding에만 insets.bottom을 적용한다.

일반 세로 화면에서는 제목/설명 실측 높이, 상태 줄(최소 48, 교체 안내·44pt 작업 버튼은 실측 높이), 트레이(기본 124), CTA(최소 52 + 상하 24), 구획 간격 총 36을 먼저 확보한다. 남은 높이를 H라 하면 갤러리 스케일 s = min(W/1060, H/1080, 0.48)이며 전체 캔버스 1060s × 1080s를 중앙에 둔다. 액자마다 다른 배율을 쓰지 않는다. 예: 390pt 화면에서 W=350, H≥364이면 s≈0.3302, 가장 좁은 oval-2 폭도 약 75.6pt다.

| 고정 순번 / 액자 | 기준 캔버스 좌상단 x,y | 원본 w,h | 390pt 화면 예상 w,h |
| ---------------- | ---------------------- | -------- | ------------------- |
| 1 oval-1         | 45, 140                | 275,424  | 90.8,140.0          |
| 2 oval-2         | 715, 225               | 229,371  | 75.6,122.5          |
| 3 square-1       | 370, 85                | 296,231  | 97.7,76.3           |
| 4 square-2       | 325, 390               | 366,476  | 120.8,157.2         |
| 5 square-3       | 705, 650               | 343,288  | 113.3,95.1          |

square-3의 오른쪽 끝은 1048로 캔버스 안에 들어온다. square-2와의 수평 간격은 원본 14px이다. 다섯 액자의 외접 사각형은 서로 겹치지 않는다.

배경은 전체 캔버스에 `cover`, 중앙 정렬한다. 원본의 중앙 조명과 바닥선을 남기되 가로 배경을 세로로 늘리지 않는다. 1060×1080 cover에서는 1536×1024 원본의 중앙 약 1005px 폭만 남아 중앙 조명이 온전히 보이고 좌우 조명 일부는 양 끝에 남을 수 있는 구성이다. 원본의 y축 전체와 바닥선은 유지한다. 세 조명을 모두 보존하려고 배경을 찌그러뜨리지 않는다. 배경·액자 장식은 접근성 탐색에서 숨긴다. 액자 아래에 큰 이름표를 추가하지 않는다.

작은 높이/가로 화면 또는 큰 글자에서 s<0.24가 필요하면 벽을 계속 축소하지 않는다. 벽·제목·상태를 세로 스크롤 콘텐츠로 전환하고, 트레이와 CTA는 고정한다. 벽 최소 스케일은 min(W/1060, 0.24), 액자 hitSlop으로 44pt 보장. 벽은 트레이 바로 위까지 스크롤할 수 있다. 드래그 중 자동 스크롤의 기준은 벽 자체 경계가 아니라 **현재 화면에서 보이는 세로 ScrollView viewport 상·하단 32pt**다. 고정 헤더·트레이·CTA는 viewport에서 제외하고, 전체 스크롤 모드에서는 전체 콘텐츠의 보이는 viewport를 사용한다. 경계에 350ms 머물면 최대 160pt/s로 스크롤하며 offset은 0~max(0, contentHeight-viewportHeight)로 제한한다. 벽이 화면 밖에 있어도 트레이에서 시작한 드래그로 viewport 상단에 머물러 벽을 드러낼 수 있어야 한다. 스크롤 후 프레임 화면 좌표를 다시 측정한다. 축소 모드 안내에 “작품을 눌러도 걸 수 있어요”를 유지한다. 큰 글자에서 트레이/안내/오류의 높이는 실측하며 텍스트를 잘라내지 않는다. 고정 트레이·CTA·안내를 제외한 높이가 160pt 미만이면 전체 콘텐츠(벽·작업줄·트레이·CTA)를 하나의 세로 스크롤로 전환한다. 이 극소 높이 모드에서는 CTA 고정을 해제해 모든 버튼에 도달 가능하게 한다. 드래그를 시작한 동안 수동 스크롤은 잠그고 가장자리 자동 스크롤만 허용한다. 320×568, 390×844, 844×390 및 글자 200%에서 실측 검증한다.

### 액자 안쪽 마스크와 레이어

원본을 관찰해 정한 아래 좌표는 **원본 이미지 픽셀 좌표**다. 전체 투명 PNG를 기준으로 한다. 모든 inset에도 동일 s를 적용한다. 사각형은 Rect, 타원은 Ellipse이며 장식 PNG가 최상단이다. 안쪽 영역 아래를 크림색 매트로 채워 투명 바깥으로 작품이 새지 않게 한다. SVG clipPath는 이미 설치된 react-native-svg 사용 가능.

| 액자     | 안쪽 마스크 x,y,w,h | 마스크 |
| -------- | ------------------- | ------ |
| oval-1   | 48,94,176,247       | 타원   |
| oval-2   | 33,96,163,232       | 타원   |
| square-1 | 41,42,213,146       | 사각   |
| square-2 | 64,94,238,301       | 사각   |
| square-3 | 63,60,213,169       | 사각   |

렌더 순서: 배경 → 마스크 안의 매트/작품 → 액자 PNG → 입력·선택 테두리 → 드래그 고스트. 마스크 가장자리의 장식과 1~2 원본 px 겹침은 허용하되 실제 PNG 중심 투명 영역 밖으로 매트가 나오지 않게 프로토타입에서 확대 검수한다. 원본 square-3 내부 가장자리에 붉은 잔색이 보여 이 부분을 새 그림으로 덮지 않는다. 리터칭 없이 실기기 크기에서 거슬리는지 Alex에게 확인 항목으로 넘긴다.

모든 작품이 모든 액자에 들어간다. 기본은 아래 표의 focus 지점 중심 cover. crop 손실이 큰 이미지와 로고는 contain을 사용한다. 타원의 contain은 이미지 비율 r=원본 폭/높이를 유지한 최대 내접 사각형으로 맞춘다. 타원 반지름 a=w/2, b=h/2일 때 이미지 높이=2/√((r/a)²+(1/b)²), 폭=r×높이로 중앙 배치한다. 고정 w/√2,h/√2 상자보다 가로·세로 로고를 크게 보여주면서 네 모서리까지 보존한다. 나머지는 매트로 채운다. 작품 원본을 자르거나 수정하지 않는다.

### 작품별 표시와 감상 라벨

focus는 원본 너비/높이에 대한 0~1 위치다. cover에서는 해당 초점을 중심에 놓고 이미지 경계를 넘지 않도록 clamp한다. contain 항목의 focus는 중앙이며 동일 정책을 트레이에도 적용한다. 트레이는 88×88 이미지 상자, 카드 폭 88 + 간격 12로 390pt에서 약 3.5개가 보인다. 이미지 아래 장르를 표시한다. 로고를 공식 작품/작가명으로 소개하지 않는다.

## Design decisions

### 스크롤, 탭, 드래그

1. 트레이에서 즉시 수평 이동은 스크롤이다. 220ms 안에 이동량이 8pt를 넘으면 long press 후보를 취소하고 스크롤에 양보한다. 220ms 동안 8pt 이내 유지하면 드래그를 활성화하고 트레이 스크롤을 잠근다. 빠른 위쪽 스와이프를 드래그로 오해하지 않는다. 탭은 드래그·스크롤 모두 시작되지 않은 짧은 누름이다.
2. 액자 역시 220ms 길게 누른 후 이동한다. 타원/사각 장식의 외접 영역 전체에서 시작할 수 있다. 고스트는 출발 이미지 상자 크기를 최대 112pt로 제한해 표시하고 손가락 위 36pt에 놓는다. 판정은 고스트 위치가 아닌 **손가락의 화면 좌표**다.
3. 드롭 영역은 액자 외접 사각형에 6pt 확장하고 캔버스에 clamp한다. 겹치면 중심까지 화면 거리, 동률이면 고정 액자 순서로 정한다. 타원의 모서리 장식 위에도 놓을 수 있게 마스크와 drop hit 영역을 구분한다. 화면·캔버스·스크롤 좌표 변환은 실제 onLayout/measure 기준이다. 드롭 가능한 범위는 확장 액자 영역과 보이는 벽 viewport의 교집합으로 제한한다. 고정 트레이·CTA 아래나 화면 밖 액자는 드롭 대상으로 판정하지 않는다. 자동 스크롤 중에는 재측정된 좌표로 판정한다.
4. 드래그 중 빈 액자는 점선 + 작은 +, 현재 대상은 2pt 실선 + “여기에 걸기/교체/맞바꾸기” 캡션. 채워진 후보도 얇은 외곽선으로 구분한다. 고스트가 출발한 액자의 그림은 35% opacity로 남겨 취소 후 돌아갈 곳을 보여준다.
5. 성공 시 160ms 스냅/페이드, 잘못 놓기·OS 취소·화면 이탈 시 180ms 복귀 후 고스트 제거. Reduce Motion에서는 위치 보간 없이 즉시 변경 또는 최대 80ms opacity만 사용한다. 드래그 이동 자체에는 접근성 공지를 하지 않는다.
6. 트레이 탭은 탭 시점 썸네일 중심과 빈 액자 중심의 **화면 좌표 거리**로 대상 선택, 동률 고정 순서. 명시적 교체 대상이 있으면 우선한다. 거리 계산에는 실제 화면 좌표로 변환한 모든 빈 액자를 포함하되, 탭 배치 대상이 화면 밖에 있으면 배치 후 해당 액자가 보이도록 세로 스크롤한다. 선택된 액자와 안내가 함께 보이는 위치로 이동하고 Reduce Motion에서는 즉시 이동한다. 빈 액자 탭은 배치 대상을 지정하지 않고 “아래 작품을 눌러 걸어 주세요”만 안내한다(기획의 가장 가까운 액자 규칙 유지).
7. 채워진 액자 탭은 2pt 선택선 + 상태 줄 “N번 액자에 새 작품을 골라 주세요”, 최소 44pt ‘작품 빼기’와 ‘취소’ 버튼을 보여준다. 다른 채워진 액자를 누르면 대상 변경. 미배치 썸네일 탭으로 교체 후 선택 해제. 제거/취소 후에도 해제. 드래그 시작은 탭 교체 선택을 해제하고 드롭 완료/취소 후 stale 대상은 남기지 않는다.
8. 배치된 썸네일은 이미지 50% opacity, 체크 아이콘 + ‘배치됨’ 배지, disabled. 같은 장르의 다른 작품은 활성. 가득 찬 벽에서 대상 없는 미배치 썸네일 탭은 “바꿀 액자를 먼저 선택해 주세요”를 상태 줄에 표시한다.

## Accessibility

- 제목→상태 안내→액자 **oval-1, oval-2, square-1, square-2, square-3**→교체 작업 버튼→트레이 순서→CTA. 시각 위치와 무관한 안정적 순서를 유지한다. 숨겨진 액자 장식/고스트는 탐색 제외.
- 썸네일 `role=button`, 라벨은 표의 감상 단서 + 장르(읽기 순서는 ‘은색 테이프로 붙인 검정·분홍 로고, 현대 미술’). hint “두 번 탭하면 빈 액자에 걸어요” 또는 “선택한 액자를 교체해요”. 배치됨은 disabled 상태와 라벨로 제공한다.
- 액자 `role=button`, “1번 액자, 비어 있음” 또는 “1번 액자, {감상 단서}, {장르}, 누르면 교체 메뉴”. `accessibilityState.selected` 반영. 역할과 라벨은 모든 취소/빼기/재시도/CTA에도 필수.
- 탭만으로 배치·교체·제거·취소·완료 가능하다. 액자 간 직접 이동/맞교체의 스크린 리더 대안은 액자 `accessibilityActions`에서 ‘2번 액자로 이동/2번 액자와 맞바꾸기’ 등 다른 네 액자별 액션을 제공한다. 활성화 후 결과와 n/5를 한 번 공지한다.
- 배치 후 “현대 미술 작품을 걸었어요. 3/5”, 교체/제거/이동도 결과를 한 번 공지. 트레이 항목이 disabled되며 포커스가 유실되면 배치 대상 액자로 포커스 이동; 항목 제거 후에는 해당 액자로 복원. 번호와 role은 바뀌지 않는다.
- 요약은 진입 시 한 번 공지하고 1.5초 뒤 저장되어도 같은 요약을 남긴다. G4에서 빠른 저장 성공 시 요약 공지가 화면 복귀 때문에 끊기는지 VoiceOver로 관찰한다. 이 문서 검수만으로 별도의 성공 대기 시간을 추가하지 않는다. 오류 공지/포커스는 `OnboardingSaveErrorBar`가 소유하므로 부모에서 중복 공지하지 않는다.
- 터치 영역 44×44pt 이상, 아이콘 버튼도 동일. 충분한 hitSlop과 인접 영역 충돌 확인. 본문 gray900/gray700, 배경 gray100/gray200; primary-dark CTA는 실제 #7C3AED 위 white. gray400/white는 disabled에만 사용한다. 활성 CTA white/primary-dark 대비는 5.70:1이다. 액자 선택에는 번호·선 두께·캡션을 병행한다.
