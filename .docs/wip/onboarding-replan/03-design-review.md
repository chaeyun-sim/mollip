## Previous issues addressed

- [x] **액자 영역 겹침**: 기존 square-2 오른쪽 691, square-3 왼쪽 690으로 x축 1px 겹침이 있었다. square-3 x=705, 캔버스 폭=1060으로 변경해 외접 영역 겹침을 제거했다. 확대 드롭 영역끼리 겹치는 경우에는 기존 거리·고정 순서 판정을 유지한다.
- [x] **포커스 대비**: 현재 primary #AB77F1은 gray100 대비 2.93:1, gray200 대비 2.76:1이다. 토큰 변경 대신 gray900 보조선과 선택 문구를 추가했다. 활성 CTA white/#7C3AED 대비는 5.70:1로 확인했다.
- [x] **극소 높이**: 트레이·CTA 고정만으로는 큰 글자/가로 화면에서 벽 영역이 사라질 수 있었다. 가용 벽 높이가 160pt 미만이면 CTA 포함 전면 세로 스크롤로 전환하도록 명시했다. 교체 작업줄도 고정 48pt 대신 버튼 포함 실측한다.
- [x] **타원 속 로고 크기**: 고정 내접 상자보다 이미지 종횡비에 맞춘 최대 내접 사각형 공식을 적용했다. 바나나 테이프 콘셉트와 모니터 탑 로고가 타원에 잘리지 않고 들어가는 정적 렌더를 확인했다.
- [x] **시안과 브리프 차이**: 시스템 대체 폰트, 모든 썸네일 contain, 배치됨 상태 누락을 수정했다. 문서의 이미지 fit/focus, 로컬 폰트 참조, 배치됨 배지를 적용했다.
- [x] **검수 상태 부족**: 빈 벽/3개 배치만 있던 보드에 5개 배치(현대 로고 4개), 교체 선택, 저장 중, 저장 실패를 추가했다. 재시도 버튼은 기존 오류 바의 보라색 강조 스타일을 반영했다.
- [x] **배경 설명**: 실제 cover 렌더에서 좌우 조명 일부가 화면 끝에 남는 점을 문서에 반영했다.

## Suggestions (nice to have)

- 타원에 전체 이미지를 담으면 여백이 커지는 작품이 있다. 원본 전체 보존을 우선하는 현 정책을 유지하되 G4에서 실제 크기로 식별성을 확인한다.
- square-3 원본 내부의 붉은 잔색은 정적 화면 크기에서 차단 수준으로 보이지 않았다. 고밀도 시뮬레이터 확대 확인 항목으로 유지한다.
- 디자인 시스템의 오래된 브랜드 hex 표는 별도 문서 정리 대상으로 남긴다. 이번에는 문서 자체가 지정한 Tailwind 정본 및 JS 미러와 일치하는 값을 사용했다.
