# Handoff — 몰립 프리미엄 결제(페이월) 화면

## 한 줄 요약

`/settings/premium` 프리미엄 결제 화면을 구현했습니다. 실제 결제 연동 전 단계로, 상품 비교 UI와 안전한 "준비중" 상태만 제공합니다.

## 변경 내용

| 항목                       | 변경                                                                     |
| -------------------------- | ------------------------------------------------------------------------ |
| `app/settings/premium.tsx` | 신규 — 프리미엄 결제 화면 (혜택 목록, 3종 요금제 비교, 비활성 구매 버튼) |
| `app/settings/_layout.tsx` | `premium` 라우트 등록                                                    |
| `app/(tabs)/settings.tsx`  | 프리미엄 배너 → `/settings/premium` 연결                                 |

## 상품 구성 (spec 개정 반영 — `01-spec-amendment-memo.md`)

| 상품              | 가격                       | 비고          |
| ----------------- | -------------------------- | ------------- |
| 6개월 (기본 선택) | ₩34,900 / 6개월 (일 193원) | 26% 할인 배지 |
| 1주               | ₩3,900 / 주 (일 557원)     |               |
| 1개월             | ₩7,900 / 월 (일 263원)     |               |

최초 spec(1일/1주/1달, 주간 기본 선택)과 실제 구현이 달라 QA 중 발견되었고, 실제 구현을 정본으로 채택하도록 확인받아 spec을 개정했습니다.

## 알아두면 좋은 점

- **네이티브 빌드 이슈 해소**: 이전 QA를 막았던 `pod install` 실패(RevenueCat 버전 충돌)는 재실행 시 이미 해소된 상태였습니다. `npx expo run:ios` 재빌드로 시뮬레이터 정상 기동 확인.
- **결제 미연동**: StoreKit/RevenueCat 실제 상품 등록, 결제 실행, 구매 복원은 spec에 명시된 대로 이번 스코프 밖입니다 — "결제 기능 준비 중" 버튼은 의도적으로 비활성화되어 있습니다.
- **1일 이용권 제외**: 원래 spec에 있던 1일 이용권은 이번 구현에서 빠졌습니다. 필요하면 별도 기능으로 다시 추가할 수 있습니다.
