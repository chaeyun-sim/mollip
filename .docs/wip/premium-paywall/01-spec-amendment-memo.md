# Spec amendment — 상품 구성 변경 (1일/1주/1달 → 6개월/1주/1개월)

## Decision

- **상품 구성 변경**: 1일 이용권 / 1주 / 1달 → **6개월(기본 선택) / 1주 / 1개월**.
- **가격 변경**: 주간 ₩6,990 → ₩3,900, 월간 ₩14,900 → ₩7,900, 1일 ₩2,990(제거) → 6개월 ₩34,900(신규, 26% 할인 배지).
- **기본 선택 변경**: 주간(weekly) → 6개월(sixMonths).

## Rationale

- Chris 구현 단계에서 장기 구독 유도를 위해 6개월 상품(할인 배지 포함)을 기본 노출하는 구성으로 전환됨.
- 1일 이용권은 자동 갱신이 아닌 별도 이용권으로, 이번 화면에서는 제외하고 추후 별도 스코프로 분리.
- 사용자 확인 결과 실제 구현(6개월/1주/1개월)을 정본으로 채택 — 코드 재작업 대신 spec을 구현에 맞춤(QA 2026-09-21).

## AC-1 개정: 가격 비교

- **Given** 사용자가 설정의 프리미엄 배너를 누르면
- **When** 결제 화면이 열리면
- **Then** 6개월 ₩34,900/6개월(26% 할인 배지), 1주 ₩3,900/주, 1개월 ₩7,900/월이 표시되고 6개월이 기본 선택된다.

## AC-2는 변경 없음

- 조건 문구·결제 준비중 상태 표시는 기존 AC-2 그대로 유효.
