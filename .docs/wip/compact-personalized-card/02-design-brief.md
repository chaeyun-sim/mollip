# Design brief

- 흰 카드 안에 작은 세로 포스터를 왼쪽에 두고, 오른쪽에는 상태 → 최대 두 줄 제목 → 한 줄 장소 순서로 전시 정보를 놓는다. 구분선 아래 한 줄 추천 이유를 둔다.
- 카드 너비는 홈의 24pt 좌우 여백을 따른다. 포스터는 88×116pt, 전체 터치 영역은 44pt 이상으로 유지한다.
- `gray900` 제목, `gray600` 장소, `brand` 추천 아이콘과 `gray700` 설명을 사용한다. 배경과 서체는 기존 디자인 시스템 토큰을 쓴다.
- 추천 근거는 아이콘 뒤에 `현대미술, 차분한, 고흐`처럼 쉼표로 나눈 짧은 태그를 모두 표시한다. 줄 수 제한 없이 필요한 만큼 줄바꿈한다. 접근성 라벨에도 전체 태그를 포함한다.
