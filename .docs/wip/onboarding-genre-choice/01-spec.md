# Spec — 온보딩 취향 선택 방식 추가

## Problem

현재 온보딩은 작품을 직접 골라 전시 벽에 배치하는 방식만 제공한다. 조작이 번거롭고 추천에 필요한 취향을 빠르게 입력하기 어렵다.

## Goals

- 작품으로 벽을 꾸미는 경험은 유지하면서 장르 칩으로 빠르게 고르는 대안을 제공한다.
- 두 방식 모두 `preferred_genres`에 같은 정규 장르값을 저장해 동일한 추천 흐름을 사용한다.

## Constraints

- 기존 벽 선택과 스킵, 저장 실패 복구 흐름을 유지한다.
- 칩 선택은 현재 온보딩에서 지원하는 정규 장르 7개만 제공한다.
- 온보딩의 칩 선택은 `preferred_wall_piece_ids`를 빈 배열로 기록한다.
- 취향 수정에서 칩 화면으로 이동할 때는 현재 벽 작품 ID를 보존한다.

## Non-goals (out of scope)

- 추천 알고리즘 또는 DB 스키마 변경 (초기 범위; 2026-10-20 후속 확장으로 별도 반영)
- 취향 설정 화면의 벽 편집 방식을 칩 방식으로 교체

## Users & context

첫 가입 후 취향 입력 단계에서 벽을 꾸미거나 빠른 장르 선택을 원하는 사용자.

## Acceptance criteria

### AC-1: 선택 방식 진입

- **Given** 사용자가 취향 온보딩 프롤로그를 본다
- **When** 계속하기를 선택한다
- **Then** 작품으로 벽 만들기 또는 장르 칩으로 빠르게 고르기 중 하나를 선택할 수 있다.

### AC-2: 장르 칩 선택과 저장

- **Given** 사용자가 칩 선택 방식에 진입한다
- **When** 하나 이상의 장르를 선택하고 시작하기를 누른다
- **Then** 선택한 정규 장르와 빈 벽 작품 ID 목록이 저장되고 기존 추천으로 이동한다.

### AC-3: 저장 실패 복구

- **Given** 칩 취향 저장이 실패한다
- **When** 사용자가 재시도한다
- **Then** 선택한 칩을 유지한 채 저장을 다시 시도할 수 있다.

### AC-4: 취향 수정에서 칩 화면 열기

- **Given** 사용자가 `내 취향 수정`에서 전시 벽을 편집 중이다
- **When** `취향 강화하기`를 누른다
- **Then** 현재 장르 선택을 미리 반영한 칩 선택 화면으로 이동하고 저장 후 취향 수정 화면으로 돌아온다.

## Risks & dependencies

- 칩 방식은 벽 선택과 동일하게 장르 단위 취향만 수집하므로 추천 정밀도 향상에는 데이터 분류 품질도 필요하다.

## Follow-up: 취향 강화하기 화면

- 취향 수정의 `취향 강화하기`는 장르를 반복 선택하지 않고 그림 분위기, 전시장 규모, 미술사조를 각각 세로 섹션으로 제공한다.
- 선택은 `profiles.preferred_taste_details`에 저장하고 추천 점수에 보조 신호로 반영한다.
- 전시 설명·장소명에 해당 정보가 명시된 경우에만 매칭한다. 장소 규모는 장소명 기반 휴리스틱이므로 정확한 면적/수용인원 분류가 아니다.
