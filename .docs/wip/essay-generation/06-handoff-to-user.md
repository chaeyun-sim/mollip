# Handoff to user

## Summary

확정 큐의 한줄평 입력과 별도 감상 생성 단계를 하나의 "감상평" 입력칸으로 합쳤습니다. 별점 다음에 직접 쓰기/생성하기 토글이 있는 입력칸이 바로 나오고, 생성 결과는 그 칸에 스트리밍으로 채워진 뒤 이어서 고칠 수 있습니다. "다음"을 눌러야 서명으로 넘어갑니다.

## What changed

- `EssayStageSection` 삭제, `EssayInputSection` 신규 — 감상평 라벨 + 토글 + 박스형 입력칸 + 에러/다음
- `ReceiptSummary` / `confirm-visits` — 별점 → 감상평 → 서명 3단계. `essayStageReady`/`onMemoDone` 제거
- 생성 횟수 한 카드당 5회. 기존 입력 텍스트는 다음 생성의 참고 재료로만 쓰이고 화면 텍스트는 새 결과로 바뀜
- 저장은 `memo` 하나. 예전에 나눠 저장된 `essay`는 memo가 비어 있을 때만 이관(둘 다 있으면 memo 유지)

## ⚠️ 알려진 한계 — 실기 확인이 필요합니다

시뮬레이터를 켰지만 이 머신에 몰립/Expo Go 앱이 설치되어 있지 않아 화면을 직접 눌러보지 못했습니다.

**요청**: 확정 큐에서 아래만 한 번 봐 주세요.

1. 별점을 매기면 "한줄평"이 아니라 "감상평" 한 칸이 바로 나오는지
2. 빈 칸에서 "생성하기"를 눌렀을 때 그 칸에 텍스트가 주루룩 채워지고, 그동안 타이핑이 막히는지
3. 생성이 끝난 뒤 글을 고칠 수 있고, "다음"을 눌러야만 서명이 나타나는지(자동으로 안 넘어가는지)
4. 생성 중에 "다음"이 눌리지 않는지
5. 확정 후 다이어리에 감상평이 보이는지
