# Spec — 마이페이지 색 구분

## Problem

밝아진 `#FAFAF8` 캔버스에서 흰색 프로필·설정 카드의 경계가 약하다. 사용자 제공 시뮬레이터 스크린샷에서도 항목 묶음이 한 덩어리로 보인다.

## Goals

- 계정 정보와 설정 항목의 시각적 위계를 분명히 한다.
- 카드와 캔버스의 경계를 중립색으로 구분한다.
- Deep Plum을 한정된 핵심 면에 사용한다.

## Constraints

- 기존 이동 경로, 잠금 상태, 텍스트, 터치 영역은 유지한다.
- 앱 전역의 밝은 캔버스는 유지한다.

## Non-goals (out of scope)

- 설정 메뉴 재구성, 계정·결제 동작 변경

## Users & context

로그인한 사용자가 마이페이지에서 계정과 설정 항목을 탐색한다. 비로그인 상태에서도 설정 그룹이 구분되어야 한다.

## Acceptance criteria

### AC-1: 카드 위계

- **Given** 밝은 마이페이지가 열린 상태
- **When** 프로필과 설정 카드가 렌더링되면
- **Then** 프로필은 브랜드색 면으로 구분되고 설정 카드는 중립색 경계로 배경과 구분된다.

### AC-2: 그룹 탐색

- **Given** 여러 설정 그룹이 나열된 상태
- **When** 사용자가 스크롤하거나 항목을 탭하면
- **Then** 그룹 제목과 항목 구분선이 보이고 기존 이동·잠금 동작은 유지된다.

## Screens / routes

| Route              | 변경                                |
| ------------------ | ----------------------------------- |
| `/(tabs)/settings` | 프로필·설정 카드 색 위계, 그룹 제목 |

## Risks & dependencies

프로필의 밝은 텍스트와 브랜드색 대비를 확인한다. 공통 `SettingsCard`의 다른 사용 화면은 회귀 확인한다.
