# Spec — 홈(둘러보기) 에디토리얼 리프레시

## Problem

- 대표 전시 캐러셀이 3.5초마다 자동으로 넘어가고, 카드 폭(`window-40`)·마진(40/20) 계산이 스냅 간격(`window`)과 어긋나 페이징이 틀어진다. 현재 위치 표시도 없다.
- 히어로 카드는 카테고리 카피(36px)가 주인공이고 실제 전시명·장소는 작게 밀려 있다. `thumbnail!`로 이미지 없음 처리도 없다.
- AI 도슨트 진입은 아이콘만 있는 FAB이라 기능이 무엇인지 알 수 없다. 지도 탐색 진입은 홈에 없다.
- 헤더는 `-mr-12` 음수 마진으로 위치를 맞추고 있다 (`ScreenHeader`의 `fullBleed`로 해결 가능).

## Goals

- 웜 뮤지엄 에디토리얼 위계: 날짜 eyebrow + Hahmlet 헤드라인 → 전시 커버 카드(전시명·장소 중심).
- 자동 재생 제거, 카드 폭 기반 반응형 스냅, `01 / 03` + 도트 위치 표시.
- 라벨 있는 "AI 도슨트" 확장형 FAB. 검색바 옆 지도 진입 버튼.
- 인기 섹션에 제목 추가, 개인화 제목 간결화.

## Constraints

- 인증(`LoginRequiredPressable`), 프리미엄/구독 로딩 라우팅, 로딩·에러·빈 상태 유지.
- 기존 토큰·폰트만 사용, 의존성 추가·커밋 없음.

## Non-goals (out of scope)

- 데이터 훅 로직 변경(`useFeaturedTrio`는 `isLoading` 노출만 추가), 다른 탭, 인기 아바타 카드 개편.

## Users & context

- 홈 탭 진입 사용자 전체(로그인/비로그인, 구독/비구독).

## Acceptance criteria

### AC-1: 자동 재생 제거와 반응형 페이징

- **Given** 대표 전시가 2개 이상
- **When** 홈에 머문다 / 가로로 스와이프한다
- **Then** 자동으로 넘어가지 않고, 한 번에 한 장씩 카드 왼쪽 끝에 정렬되어 멈춘다(폭 = 화면 − 48, 간격 12).

### AC-2: 위치 표시

- **Given** 대표 전시 2개 이상
- **When** 페이지가 바뀐다
- **Then** `01 / 03` 숫자와 도트(활성은 긴 바)가 갱신되고 접근성 레이블이 현재 위치를 읽는다.

### AC-3: 전시명·장소 중심 커버 카드

- **Given** 대표 전시가 있을 때
- **When** 카드를 본다
- **Then** 실제 전시명(Hahmlet), 장소, 상태가 보이고 카테고리 카피는 상단 작은 레이블이다. 이미지가 없으면 폴백 이미지가 보인다.

### AC-4: AI 도슨트 액션

- **Given** 홈 화면
- **When** "AI 도슨트" 라벨 FAB을 누른다
- **Then** 구독 상태 로딩 중엔 이동하지 않고, 프리미엄이면 가이드 생성, 아니면 프리미엄 화면, 비로그인이면 로그인으로 간다.

### AC-5: 검색·지도 탐색

- **Given** 홈 상단
- **When** 검색바 / 지도 버튼을 누른다
- **Then** 각각 `/search`, `/(tabs)/map`으로 이동한다.

### AC-6: 헤더 해킹 제거 및 상태 보존

- **Given** 홈 로딩·에러·빈 상태
- **Then** `ScreenHeader fullBleed` 사용, `-mr-12`·`px-6` 보정 제거. 로딩 시 히어로 스켈레톤, 에러·빈 상태는 기존 섹션 컴포넌트 유지.
