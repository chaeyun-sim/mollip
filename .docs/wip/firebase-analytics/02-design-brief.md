# Design brief

## Design intent / Tokens / Layout
UI 변경 없음. 기존 한국어/영어 문구·색·폰트·간격·접근성·터치 타겟 유지.

## States / Accessibility
Analytics 초기화·전송 실패는 UI 경고나 버튼 지연을 만들지 않는다. 화면/이벤트 이름은 개발 내부 코드로만 둔다. G4는 레이아웃 없는 M 작업으로 별도 프로토타입 생략.

## Out of design scope
새 사용자 동의 화면, 대시보드, 수집 설정 UI.
