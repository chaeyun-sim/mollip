# Design brief — 홈 도록형

## Design intent

- 전시 도록 한 권을 넘기는 느낌. 큰 도판 하나, 정돈된 캡션, 번호 매긴 목차, 마지막 장의 명화.
- 포스터는 '작품'으로 대우한다 — 위에 아무것도 얹지 않고, 모서리는 거의 직각(4px), 그림자 없음.
- 위계는 색이 아니라 **크기·세리프·여백·헤어라인**으로 만든다.

## Tokens

- Background `bg-gray100` (#F8F6F2) / 다크 밴드 `bg-bg-dark`
- Ink `text-gray900` / 보조 `text-gray700` / 캡션 `text-gray600`
- 헤어라인: 섹션 상단 `border-gray900` 1px, 행 구분 `border-gray300` 0.5px
- 강조: `text-primary-dark` — 마감 D-day에만
- Font: Hahmlet(제목·숫자), Pretendard(캡션·UI)
- Radius: 도판 4px, 버튼 full

## Design decisions

- 캐러셀 제거: 3장을 '커버 + 도판 2'로 한 화면에 펼친다(도록 스프레드). 넘겨봐야 보이는 콘텐츠가 없어진다.
- 이미지 섹션은 01 하나뿐 → 과거 "포스터 3연속" 피드백 해소.
- 지도 버튼 제거(탭 중복), FAB 제거 → 그 자리에 라벨 있는 도슨트 pill(`bg-gray900`, 유일한 다크 버튼).
- 오늘의 명화 CTA는 보라 → 흰 버튼(다크 밴드 위 최고 대비, 강조색 한 곳 원칙).

## States

- Loading: 커버 4:5 스켈레톤 / 인덱스 행 3개 스켈레톤
- Empty: 01은 문구, 02·03은 섹션 숨김
- Error: 추천만 재시도
- Success: 위 레이아웃

## Accessibility

- 커버·도판·행 각각 `button` + `제목, 장소, 상태/D-day` 라벨
- 도슨트 pill 44pt 높이, `accessibilityHint` 유지
- 대비: primary-dark on #F8F6F2 ≈ 5.4:1, gray600 캡션 ≈ 4.5:1, 흰 버튼 위 gray900 ≫ 7:1
