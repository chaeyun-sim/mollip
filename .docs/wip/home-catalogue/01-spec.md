# Spec — 홈(둘러보기) 도록형 재설계

## Problem

- 포스터 위에 흰 Hahmlet 제목 + 그라데이션을 얹어 포스터 자체 타이포와 글자가 이중으로 겹친다 — 홈에서 가장 시끄러운 지점.
- 강조 요소가 흩어져 있다: 보라 D-day 배지 다수, 검정 지도 버튼, 검정 확장형 FAB, 보라 탭.
- 지도 진입이 헤더 버튼·하단 탭에 중복. AI 도슨트 FAB가 콘텐츠(마감 레일)를 가린다.
- 과거 피드백(`home-magazine-sections` 8차): "포스터 섹션 3연속이 산만" — 이미지 섹션 수를 줄여야 한다.

## Goals

- 전시 도록(카탈로그)·포스터 같은 인상: **이미지는 적게·크게, 나머지는 타이포로.**
- 포스터 위에는 아무것도 얹지 않는다. 캡션은 도판 아래 '도판 설명'처럼.
- 섹션은 번호(01, 02 …) + 헤어라인 룰로 구분 — 카드 배경/배지/그림자 제거.
- 강조색(primary-dark)은 '곧 막을 내려요'의 D-day 한 곳에만.

## Constraints

- 데이터 훅(`useExploreScreenData`, `useFeaturedTrio`, `usePopularExhibitions`, `useDailyArtwork`) 로직·중복 제거 순서(대표 → 마감 → 추천) 유지.
- 라우팅 유지: 상세 `/(explore)/{id}`, 마감 전체 `/search?closing=1`, 검색 `/search`(sharedTransitionTag 유지), 북마크·알림(로그인 필요), 도슨트(구독 로딩 중 무시 / 프리미엄 → create-description / 아니면 premium).
- 로딩·빈·에러(추천 재시도) 상태 유지. 이미지 없음은 `ImageFallback`.
- 기존 토큰·폰트만. 신규 의존성·백엔드 없음. 커밋 없음.

## Non-goals (out of scope)

- 다른 탭·검색·상세 화면 변경, 탭바 디자인 변경.
- 데이터 선정 로직(특별전/인기/예정 고르기, 마감 기준 1~14일) 변경.
- 오늘의 명화 진행 기록 로직 변경.

## Users & context

- 앱을 열자마자 "지금 볼 만한 전시"를 훑는 관람객. 작품 앞에서는 바로 AI 도슨트로 가고 싶다.

## Acceptance criteria

### AC-1: 마스트헤드 정리

- **Given** 홈 진입
- **When** 상단을 본다
- **Then** 로고·북마크·알림 헤더 아래 날짜 줄 오른쪽에 라벨 있는 'AI 도슨트' 버튼이, 그 아래 검색바 + 지도 버튼(유지)이 있다. 화면 우하단 FAB는 없다. 도슨트 버튼은 기존 FAB와 같은 인증·구독 라우팅을 따른다.

### AC-2: 01 이번 주의 전시 — 커버 + 도판

- **Given** 대표 전시가 1개 이상
- **When** 첫 섹션을 본다
- **Then** 1번 전시는 콘텐츠 폭 4:5 포스터(오버레이·그라데이션 없음)로, 아래에 분류·상태 줄, Hahmlet 제목, 장소·기간이 놓인다. 2·3번은 그 아래 2열 도판(4:5)과 짧은 캡션으로 놓인다. 가로 캐러셀·페이지 표시는 없다. 탭하면 상세로 이동.
- 로딩 중엔 커버 자리 스켈레톤, 0개면 "지금 소개할 전시가 없어요".

### AC-3: 02 곧 막을 내려요 — 타이포 인덱스

- **Given** 1~14일 안에 끝나는 전시가 있다
- **When** 섹션을 본다
- **Then** 이미지 없이 행마다 큰 D-day(Hahmlet, primary-dark) + 제목 + 장소가 헤어라인으로 구분된 목록(최대 5개)이다. '전체' 링크는 `/search?closing=1`. 대상이 없으면 섹션 숨김, 로딩 중엔 행 스켈레톤.

### AC-4: 03 추천 — 번호 인덱스 (개인화 사용자만)

- **Given** 선호 장르가 있고 위에 안 나온 추천이 있다
- **When** 섹션을 본다
- **Then** 번호(01…) + 제목 + 장소·기간의 타이포 인덱스(최대 4개). 에러면 다시 시도, 비개인화면 섹션 없음.

### ~~AC-5: 오늘의 한 점~~ — 사용자 요청으로 홈에서 제거 (2026-10-09)

- **Given** 오늘의 명화가 있다
- **When** 맨 아래까지 스크롤
- **Then** 다크 밴드에 명화(contain), 제목·작가·연도, 흰 버튼 'AI 도슨트 해설 듣기'(기존 라우팅), 출처 표기. 섹션 번호는 앞 섹션 수에 맞춰 이어진다. 탭바에 가리지 않는다.

## Risks & dependencies

- 포스터 비율이 제각각 → 4:5 cover 크롭으로 일부 잘림(도록 도판처럼 의도). 포스터 위 텍스트를 안 얹으므로 잘림이 정보 손실은 아님.
- 지도 버튼 제거 — 탭바 '지도'로 동일 진입 가능.
- FAB 제거로 도슨트 진입이 스크롤 시 사라짐 — 마스트헤드 버튼 + 오늘의 한 점 CTA 두 곳으로 보완.
