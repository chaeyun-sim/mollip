# Design brief — 나의 작은 미술관

## Design intent

내 기록이 **미술관 벽에 걸린 액자**처럼 보이게 한다. 장식(티켓·도장) 대신 **여백·액자·캡션 라벨**이라는 전시장의 문법으로 위계를 만든다. 가장 풍부한 색은 항상 전시 포스터·내 사진이고, UI는 `canvas` 위의 중립 면과 Deep Plum 한 색으로만 말한다 (DESIGN_SYSTEM §1.1).

## Tokens

- 배경 `canvas #FAFAF8`, 글자 `ink #2D2D23`, 강조 `brand #5F1D3E` (한 화면 한 곳)
- 액자 면 `white` + 얇은 테두리 `border-[0.5px] border-divider`(Mushroom), 사진 뒤 매트(액자 안쪽 여백)는 `white`
- 이미지 없는 기록의 면: `surface-neutral`/`blanket` 중 기록 키(전시 id)로 결정적 선택 — **한 화면에 한 계열만**(blanket 고정, 톤 변화는 `surface-neutral`과 교대). 파스텔은 쓰지 않는다 (§1.3: 포스터 목록 위 반복 금지)
- 제목·전시명: `font-hahmlet-bold`/`font-hahmlet-semibold`, 라벨 본문·메타: `font-pretendard-*`
- 날짜 등 제한된 편집 요소: `editorial #854628` (캡션의 날짜만)
- 그림자 없음(액자는 선과 여백으로 구분). 모션용 그림자만 `shadow-chip`

월 정렬은 최신 월이 위. 같은 월은 방문일 내림차순을 열에 번갈아 배치(좌→우).

### 기록 상세 — 도록 (`diary/[date]`)

위→아래: 큰 이미지 영역(가로 스와이프 페이저, 비율 4:5, 페이지 점 표시 — 이미지 1장이면 점 없음) → 캡션 블록(전시명 Hahmlet bold 22, 장소·날짜, 별점 5개 읽기 전용 뱃지) → 한 줄(Hahmlet regular 16, 인용 느낌 좌측 `border-l-[2px] border-brand` — brand는 이 한 곳만) → "들은 해설"(번호 + 작품명 + 재생 버튼 `DiaryGuidePlayer`) → 하단 '편집'·'삭제'는 헤더 우측 메뉴(`IconButton`).

- 이미지가 없으면 상단 이미지 영역 대신 `blanket` 면에 전시명 타이포(Hahmlet bold 28)를 크게 배치한다.
- 편집은 같은 화면의 시트에서 별점·한 줄·사진을 고친다(기존 동작 재사용).

### 작성 — 3단계 (`diary/record/*`)

공통: 상단 스텝 표시 — **입장 · 감상 · 캡션** 세 단어와 얇은 진행선(현재 단계만 ink, 나머지 gray400). 하단 고정 `Button` (다음 / 기록 남기기). 뒤로가기는 이전 단계(입력 유지).

1. **입장**: 기존 고르기 화면(추천 → 검색 → 직접 기록) 위에 방문일 칩(오늘·어제·날짜 선택)을 선택 카드 아래에 둔다. 전시를 누르면 카드가 선택 상태(brand 테두리 2px + 체크 아이콘)가 되고 하단 '다음'이 활성화된다. 도슨트 관람은 날짜 칩 대신 "N월 N일 · 도슨트 관람일" 고정 배지.
2. **감상**: 상단 선택 전시의 작은 액자 프리뷰(포스터 + 전시명) → 별점(큰 별 5개, 필수) → 사진 그리드(최대 6, 선택).
3. **캡션**: 상단에 **실제 캡션 라벨 미리보기**(액자 + 라벨, 입력에 따라 실시간 갱신) → 한 줄 입력(100자, 카운터) + 'AI로 다듬기'. '기록 남기기' 탭 → 라벨 미리보기가 위로 올라가 벽 위치로 축소되며 페이드(약 900ms) → 홈으로 `dismissAll`, 새 액자가 첫 칸에 약한 페이드 인.

## Design decisions

- **소품 제거**: 탑승권·도장·바코드·티켓 색 팔레트(`ticketColor`)를 쓰지 않는다. 기록 간 구분은 비율·여백만으로.
- "기억에 남는 한 점"은 저장 필드가 없어 이번 범위에서 제외한다(스펙 Non-goals).
- 액자 비율을 해시로 고정해 새로고침마다 레이아웃이 튀지 않게 한다.
- 별점은 상세·캡션 미리보기에서 숫자 대신 별 아이콘 + 접근성 라벨에 "5점 만점 4점".

## States

- Loading: 벽 — 액자 스켈레톤 4개(`surface-neutral`), 상세 — 이미지 영역 스켈레톤.
- Empty: 위 빈 상태. 대기 스트립은 항목이 없으면 렌더하지 않는다.
- Error: 이미지 로드 실패 → 이미지 없는 기록과 같은 타이포 면으로 대체. 저장 실패는 기존 Alert, 입력은 보존.
- Success: 액자 걸림 모션 후 홈. 새 액자 약한 페이드 인.
- Disabled: '다음/기록 남기기'는 비활성 시 `surface-disabled` + `text-secondary`(Button 최신 동작).

## Accessibility

- 액자: `accessibilityRole="button"`, label `"{전시명}, {날짜}, 별점 {n}점, 기록 보기"`.
- 대기 카드: label `"{전시명} 기록하기, {N}일 남음"`.
- 스텝 표시: `accessibilityRole="progressbar"`, value `"3단계 중 2단계, 감상"`.
- 별점: `adjustable` 역할(증감 제스처)과 현재 값 라벨. 터치 타겟 ≥ 44pt(별 34px + hitSlop 5).
- 액자 걸림 모션: `AccessibilityInfo.isReduceMotionEnabled`이면 페이드만(이동·축소 생략).
- 대비: 캡션 gray600/gray700 on canvas ≥ 4.5:1 확인, editorial(#854628) 날짜는 11px 본문 사이즈라 6.92:1(§1.5)로 허용. 이미지 위 글자는 두지 않는다(캡션은 이미지 밖).
- 색만으로 선택 전달 금지: 전시 선택 카드는 체크 아이콘 + 테두리 2px.
