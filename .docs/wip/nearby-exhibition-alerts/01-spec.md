# Spec — 근처 전시 알림

## Problem

알림 설정에 근처 전시 알림이 준비 중으로 노출되지만 실제 기능은 없다. 사용자가 이동 중 주변 전시를 놓치지 않도록 위치 진입 기반 알림을 제공한다.

## Goals

- 사용자가 직접 켜고 끄는 위치 기반 근처 전시 알림을 제공한다.
- 위치는 기기에서만 처리하고 서버에 이동 경로를 저장하지 않는다.
- 근처에 전시가 여러 개면 한 알림으로 묶어 대표 전시와 개수를 안내한다.
- 전체 발송은 하루 최대 1회, 최근 7일 동안 최대 2회로 제한한다.
- 같은 전시는 알림 후 14일 동안 다시 알리지 않는다.
- 알림 탭은 지도 화면을 열어 주변 전시를 볼 수 있게 한다.

## Constraints

- 알림은 명시적으로 켠 경우에만 동작한다. 기본값은 꺼짐.
- 백그라운드 진입 감지는 OS 지오펜싱에 맡기고, 현재 위치와 전시 데이터는 기기에서 처리한다.
- 좌표가 연결된 박물관/미술관의 현재 진행 중 전시만 대상이다.
- iOS는 한 번에 최대 20개 지역만 모니터링한다. 현재 위치 20km 안에서 가까운 대상부터 등록하고 앱이 다시 활성화될 때 갱신한다.
- 앱이 포그라운드이거나 최근 1시간 안에 사용 중이면 위치 알림을 표시하지 않는다.
- 사용자가 앱을 강제 종료한 동안 동작은 OS별 제한을 받으며 QA 보고서에 명시한다.
- 로그아웃/권한 철회/알림 비활성화 시 지오펜스와 예약 알림을 중단한다.

## Non-goals (out of scope)

- 서버로 실시간 위치 전송 또는 원격 위치 추적
- 좌표가 없는 전시의 주소 지오코딩
- 자동 결제 알림
- 알림 시간대 설정 및 개인화 반경 설정
- 주변 전시의 상시 목록 화면 (지도 기능으로 이동)

## Users & context

근처 전시를 발견하고 싶은 사용자. 계정에 위치 이동 정보를 저장하지 않으며, OS 위치 권한과 알림 권한을 허용해야 한다. 설정 화면에서 언제든 끌 수 있다.

## Acceptance criteria

### AC-1: 명시적 활성화와 권한 안내

- **Given** 알림 설정에서 근처 전시 알림이 꺼져 있다
- **When** 사용자가 켠다
- **Then** 기능 설명을 먼저 보여주고 알림 및 위치 권한을 요청한다. 필요한 권한이 모두 허용되면 설정을 저장하고 지오펜싱을 시작한다. 거부/오류 시 꺼진 상태를 유지하고 복구 안내를 보여준다.

### AC-2: 후보 지역 등록

- **Given** 기능이 활성화되어 있고 현재 진행 중인 전시 데이터가 있다
- **When** 현재 위치와 전시 목록을 조회한다
- **Then** 좌표가 유효한 전시 장소를 800m 이내 거리 기준으로 묶고, OS 제한 안에서 가까운 지역부터 지오펜스로 등록한다. 박물관 한 곳에 여러 전시가 있으면 알림 후보 개수에 각각 포함한다.

### AC-3: 진입 알림과 대표 전시

- **Given** 사용자가 등록된 지역 밖에 있고 후보 전시가 현재 진행 중이다
- **When** 기기가 해당 지역에 진입한다
- **Then** 대표 전시 1개와 해당 지역의 전시 개수를 안내하는 알림을 한 번 표시하고, 알림 데이터에 지도 진입 정보를 포함한다.

### AC-4: 빈도 및 중복 제한

- **Given** 최근 알림 기록이 저장되어 있다
- **When** 지오펜스 진입 이벤트가 발생한다
- **Then** 하루 1회 초과, 최근 7일 내 2회 초과, 같은 전시의 14일 이내 재알림은 모두 차단한다. 이벤트가 연속·중복 전달되어도 결과는 동일하다.

### AC-5: 설정 해제 및 권한 철회

- **Given** 근처 전시 알림이 켜져 있다
- **When** 사용자가 끄거나 OS 권한을 철회한다
- **Then** 등록된 지오펜스와 이 기능의 예약 알림을 정리하고 이후 알림을 만들지 않는다.

### AC-6: 알림 탭 이동

- **Given** 근처 전시 알림이 표시되어 있다
- **When** 사용자가 알림을 탭한다
- **Then** 앱의 지도 탭으로 이동해 알림의 대표 전시 장소를 중심으로 주변 전시를 탐색할 수 있다.

### AC-7: 예외와 데이터 실패

- **Given** 위치 권한, 네트워크, 장소 좌표 또는 OS 지오펜싱을 사용할 수 없다
- **When** 활성화/갱신/진입 처리를 수행한다
- **Then** 앱이 중단되지 않고, 설정 상태와 알림 기록이 실제 활성 상태와 일치하도록 복구 또는 오류 안내를 제공한다.

| `/notifications/settings` | 준비 중 행을 명시적 활성화 토글 및 안내 상태로 교체 |
| 알림 딥링크               | `nearby_exhibition` 탭 시 지도에 대표 박물관 포커스 |

## Risks & dependencies

- 백그라운드 위치 권한은 높은 신뢰 요구와 플랫폼별 제한이 있다. 목적·중단 방법을 OS 요청 전에 설명한다.
- 지오펜스 이벤트의 시간/좌표 정확도는 OS가 제어하며, 실제 기기에서 추가 검증이 필요하다.
- iOS의 20개 영역 제한 때문에 앱 활성화 시 최근접 대상 목록을 다시 등록한다.
- 활성 전시 데이터는 `exhibitions`와 좌표가 있는 `museums` 관계에 의존한다.
- Expo SDK 56 `expo-location` 백그라운드 지오펜싱에는 `expo-task-manager` 설치와 네이티브 재빌드가 필요하다.
