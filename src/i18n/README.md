# 한국어 우선 번역

- `locales/ko.json`이 기준 원문이다. 한국어를 먼저 확정하고 동일한 키의 `en.json`을 번역·수정한다.
- 사용자가 정리한 문구를 화면의 고정 UI·접근성 라벨과 연결한다. 전시 제목·장소·작가명·검색 질의와 AI 생성 언어는 바꾸지 않는다.
- **언어 선택 기준**: `expo-localization.getLocales()[0].languageCode`가 한국어(`ko`)면 한국어, 그 외 지원되지 않는 언어는 영어로 표시한다. 언어 정보가 없으면 한국어를 기본값으로 사용한다. 지역, GPS 위치, 스토어 국가는 사용하지 않는다.
- 영어 번역 누락 시 한국어로 대체한다(`fallbackLng: 'ko'`). 기기 언어 변경은 foreground 복귀 시 다시 읽고, Android 실행 중 설정 변경도 반영한다. OS가 설정 변경으로 앱을 종료하면 재시작 시 적용한다.
- 앱 표시 언어는 기기 언어를 따르므로 `en-KR`은 영어, `ko-US`는 한국어로 표시한다.
- `t('departures.hero_text', { count })`처럼 기본 키와 `count`로 호출한다. `_one`/`_other`는 i18next가 선택한다. 단복수가 있는 경우 중복 기본 키를 추가하지 않는다.
- 두 파일의 키와 치환 변수는 동일하게 유지한다.
- 기존 카탈로그와 대응하는 문구를 연결한 범위다. 번역 카탈로그에 없는 고정 문구는 아직 한국어로 남을 수 있다.
- `expo-localization` 추가로 네이티브 리빌드가 필요하다. 앱 언어 설정의 지원 언어는 `ko`, `en`으로 등록한다.
